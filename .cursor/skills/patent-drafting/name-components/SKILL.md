# 部件命名

技术方案由技术特征体现；权项和说明书都要用名称把特征说清楚。交底里的叫法常不全面、不准确，不能直接当专利用名。

本 skill 在 **`write-claims` 接受独权构思第二版之后首先启用**：同时优化（1）该独权里出现的名称，（2）交底书 / 理解稿里出现、说明书仍会用到的名称。重点放在作出改进的专用件上，而不是标准件。

只出命名表，不写权利要求文句、不写说明书章节。命名是换标签，不改独权已经确定的特征集合。

## 何时启用

- `write-claims` 已接受独权构思结果（全流程强制，且为该 skill 的第一步）
- 用户要求命名、术语表、把交底用名改成专利用名
- 后续撰写中出现新对象时再入一次，增补命名表

不要在独权构思之前启用本 skill 来「先起名再构思」。独权构思阶段用交底/理解用词即可。

## 门禁

- 前置：已有理解稿；全流程中还应已有 `02-independent-claim.md` 第二版（用户只拿交底来问命名时，至少要有对象清单）
- 不输出权利要求或说明书正文
- 一名不定稿：有争议标待确认，不擅自定关键名

## 目标

名称应让阅读者第一眼能明白所指，不必猜。做到**贴切、恰当、实用、简便**：不过分简单或繁琐，不怪异，不歧义。权项用名与说明书用名必须是同一套；权项简明，说明书可以更细，但同一对象不得两套叫法。

同一对象只用一个正式名称。交底别称列入对照表，后续撰写禁止再用别称当正式名。

---

## 做之前先收齐对象

从两处收集，合并去重：

1. **独权中的命名**：第二版独权里的主题、部件、部位、步骤对象、状态词等
2. **交底书中的命名**：理解稿对象清单、附图、未进入独权但实施例会用到的零件/工装/物料

标出每个对象：交底原名、在独权中是否出现、属于系统 / 部件 / 零件或部位、是否标准件。

机械产品先按结构分成几个大的**系统**，再拆到部件、零件、部位。命名时大的组成用系统/总成名，细节用零件或部位名，层次不要混在一个词里说不清。

**标准件**（螺钉、轴承等常用标准件）：可用通用名，不是本步重点。  
**改进的专用件**：才是命名重点。不考虑其特征就草率起名，后面描述会乱，甚至影响保护范围。

方法专利：对操作对象、工装、介质、中间产物用同一套原则；步骤名用「动作 + 对象」说清楚即可，不要用口号当步骤名。

---

## 命名方式（非标准件）

先看该对象最明显、最能把它和其他类似件分开的特征，再选一种方式；必要时把两种方式拼在一起。基本名称往往要和其他词组成词组才反映特征；不致混乱时也可以单独用基本名。

### 1. 基本名称

能在机械设计手册一类资料里查到的基础词，是大多数名称的词根。例如：板、杆、套、块、网、管、轮、轴、箱、壳、架、盘、框、罩。

- 按形状：杆、套、块、网、管
- 按功能：轮、轴
- 按抽象形态：箱、壳、架、盘、框、罩

单独用基本名足够区分时，不要再叠一串修饰。

### 2. 复合名称（最常用）

在基本名上加一个能把它和其他类似件分开的特征。按特征类型选：

| 类型 | 何时用 | 例子（仅说明构词，不套用到本案） |
| --- | --- | --- |
| 功能类 | 功能决定主要结构 | 垫圈、夹板、支撑柱、导柱、定位环、防尘罩、进油管 |
| 形状类 | 总体形状是主要特征 | 斜顶、凸轮、曲柄、圆管、弯板 |
| 材料类 | 特征主要在材料不在形状构造 | 橡胶套、铜垫、绝缘板 |
| 位置及方向类 | 特征在安装位置或方向 | 上夹板、外壳、前梁、中轴 |
| 直述类 | 从属某部件或含特定所属 | 油箱盖、曲轴箱、空调接口 |
| 比拟类 | 外形酷似某物、一看就懂 | 三通接头、棘爪、叉架 |
| 方法类 | 制法是显著特征 | 铸造摇臂、焊接副车架 |

优先选**最能把它和相邻件区分开**的那一类。功能能分开就用功能；一堆都叫「板」再用形状或位置。不要堆砌：上+导+支撑+斜+板，除非缺了就会混。

部位（某零件上的面、槽、孔、缘）同样用：形状（凹槽、通孔）、位置（上表面、前端）、功能（导向槽、进油孔）或直述（与某某配合的配合面）。

## 选用与校核

对每个待命名对象：

1. 它是标准件还是改进专用件？标准件用通用名。
2. 它在系统里的层级是什么？
3. 最明显特征是功能、形状、材料、位置、所属、外形比拟，还是制法？
4. 选出正式名称；对照交底原名。
5. 检查：会不会和另一对象撞名或看起来像同一件？会不会让人理解成别的结构？过长、过怪、像商标或型号吗？
6. 独权里用过的交底名，必须有对应正式名；正式名代入独权后，特征集合应仍能对上，只是用词变了。

若某一名称一旦换上，独权的技术含义跟着变了：不要硬改特征。标出来，交回 `conceive-independent-claim` 或请用户确认。

方法对象没有「板杆套」时，仍用「基本名 + 特征」：工装、夹具、介质、料、区、工位、信号等当基本名，再加功能或位置。

## 输入 / 输出

**输入**

- `02-independent-claim.md` 第二版独权（及其中出现的全部名称）
- 理解稿对象清单与交底原文用词
- 附图标记（有则用）

**输出**（`cases/<案号>/03-naming.md`，案号未知用 `draft`）

| 字段 | 内容 |
| --- | --- |
| 正式名称 | 权项与说明书唯一用语 |
| 交底 / 独权构思原名 | 对照，后续禁止当正式名 |
| 层级 | 系统 / 部件 / 零件 / 部位（方法则为对象 / 工装等） |
| 命名方式 | 基本名或哪类复合（可组合） |
| 是否出现在独权 | 是 / 否 |
| 标准件 | 是 / 否 |
| 待确认 | 有争议则填，不定稿 |

文末附：**独权用名替换表**（构思稿用词 → 正式名称），供 `write-claims` 改写独权。同物一名；未定项标 `【待确认】`。
