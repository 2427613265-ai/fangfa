# 部件命名

技术方案由技术特征体现。交底用名常不全面、不准确，不能直接当专利用名。

在 **`write-claims` 接受独权构思第二版之后首先启用**：同时优化（1）该独权里的名称，（2）交底书/理解稿里说明书仍会用到的名称。只出命名表，不写权项文句。命名换标签，不改独权特征集合。

权项撰写时的连接有形化（A042）、大小层级（A031）见 `write-claims`；本 skill 负责把每个对象的**正式名称**定对。

## 何时启用

- `write-claims` 已接受独权构思结果（全流程强制，且为该 skill 第一步）
- 用户要求命名、术语表、把交底用名改成专利用名
- 后续出现新对象时再入一次

不要在独权构思之前先起名。有争议标 `【待确认】`，不擅自定关键名。

## 收集对象

合并去重：

1. 第二版独权中的主题、部件、部位、步骤对象等
2. 交底/理解稿对象清单、附图、未进独权但实施例会用到的对象

标出：交底原名、是否出现在独权、层级（系统/设备/装置/单元/部件/构件/部位）、是否领域通用件。

层级大小（与权项一致）：系统＞设备＞装置＞单元＞部件＞构件＞详细结构。单元、组件、模块可自定义；**模块**通常一体成块，组件和单元不必。改进的专用件是命名重点；卡扣、螺栓、电机等通用件直接用领域通用名。

---

## 通用格式（A005）

**修饰语 + 名词。**

名词分两类：

| 有形名词（有一定结构、构造） | 无形名词（不具结构、构造） |
| --- | --- |
| 管、套、环、凸缘、凸起、条、板、杆、梁、柱、壁、槽、孔、豁口、开口、通道、流道 等 | 结构、构件、部件、组件、模块、器件、单元、机构、装置、设备、系统 等 |

「单元」不要与有形名词混用成看不出层次的词。独权里的上位名需要从权或说明书有下位概念支撑。

### 选用顺序

独权中的名称：优先方式 1，其次方式 2。从权和说明书可用 3–11 做下位、区分和展开。方位类（方式 3）不推荐，尤其不要用于独权。

| # | 方式 | 独权 | 说明与例子 |
| --- | --- | --- | --- |
| 1 | **功能 + 无形名词** | 五星，万能一 | 上位，须有下位支撑。驱动机构、杀菌消毒单元、连接构件、卡接组件、防脱落组件 |
| 2 | **功能 + 有形名词** | 四星半，万能二 | 上位，须有下位支撑。支撑环板、诱变孔、支撑梁、支架、进液通道、定位槽、隔挡壁 |
| 3 | 方位 + 有形/无形名词 | **不推荐** | 后壁、前壁、里层、外层、横梁、纵梁 |
| 4 | 形状 + 有形名词 | 从权/说明书 | 圆形通孔、环形网板 |
| 5 | 形状 + 无形名词 | 从权/说明书 | 条形构件、圆柱体 |
| 6 | 材料 + 有形/无形名词 | 从权/说明书 | 铝合金后车架、铝合金构件 |
| 7 | 制造方法 + 有形/无形名词 | 从权/说明书 | 冲压孔、锻造构件、冲压构件 |
| 8 | 形状 + 功能 + 无形名词 | 从权/说明书 | 环形卡接构件 |
| 9 | 所属领域通用名 | 适合标准件/通用件 | 卡扣、卡箍、三通、阀门、螺栓、电机、发电机、导轨、滑轮、丝杠 |
| 10 | 基于归属关系 | 从权/说明书常用 | 转轴孔、发动机过滤器、电机转子 |
| 11 | 序号 + 有形/无形名词 | 须区分时 | 第一键槽、第二键槽、第一充气嘴、第二充气嘴 |

可把两种方式拼在一起，但独权不要堆砌修饰。能用方式 1 说清的，不要在独权里改成方式 4–8。

开始用有形名词后，后续权项里该对象的连接宜写成套设、固定、可拆卸安装、可滑动设置等（A042），本表在「命名方式」栏标出是否有形名词，供 `write-claims` 使用。

方法专利的操作对象、工装、介质：无形名词用单元/装置/工装等，有形名词用槽、孔、通道等，同样优先功能+名词。步骤名用动作+对象，不要用口号。

## 校核

1. 独权用名是否主要是方式 1 或 2？方式 3 是否误用于独权？
2. 方式 1、2 的下位是否能在从权或交底实施例中找到支撑？
3. 同物是否一名？会不会和另一对象撞名？
4. 正式名代入独权后，特征集合是否仍能对上（只换词不换方案）？
5. 层级词是否符合系统＞…＞构件？模块是否被误用于非一体结构？
6. 通用件是否误造成了生造上位名？

名称一换就改变技术含义：不要硬改，交回独权构思或请用户确认。

## 输入 / 输出

**输入**：`02-independent-claim.md` 第二版；理解稿对象清单与交底用词；附图标记（有则用）。

**输出**（`cases/<案号>/03-naming.md`）：

| 字段 | 内容 |
| --- | --- |
| 正式名称 | 权项与说明书唯一用语 |
| 交底 / 构思原名 | 对照，后续禁止当正式名 |
| 名词类型 | 有形 / 无形 |
| 命名方式 | 上表 1–11 的编号与组合 |
| 层级 | 系统 / 设备 / 装置 / 单元 / 部件 / 构件 / 部位 等 |
| 是否出现在独权 | 是 / 否 |
| 待确认 | 有争议则填 |

文末附：**独权用名替换表**（构思用词 → 正式名称）。同物一名。

## 边界

- 不在独权构思之前定专利名
- 不在命名时增删独权技术特征
- 理解阶段的领域词释义不是本表
