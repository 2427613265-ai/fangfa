# 从权撰写（架构）

**流水线第 4 步。** 依附已完成的独权做附加限定。本阶段只定职责与契约，从权布局细则待补。

## 架构角色

把理解稿中未进入独权的优选 / 附加特征，以及独权 skill 标出的**关键创新点**，按引用关系写成从属权利要求。用词必须来自命名表，并与独权（第二版）主题一致。

## 何时启用

- 独权文本已存在，进入权利要求书其余部分
- 用户要求写从权、补从权、调整从权引用
- 无独权时：先启用 `write-independent-claim`，不在本 skill 里临编独权

## 门禁

- 必须已有独权正文（`03-independent-claim.md`）。
- 必须已有理解稿与命名表。
- 不重写独权的必要特征集合；若发现独权缺必要特征，停写从权并回到独权 skill。

## 输入 / 输出契约

**输入**

- 独权正文与最小特征集 / 关键创新点（读 `03-independent-claim.md` 第二版及关键创新点清单）
- 理解稿中的优选 / 附加特征
- 命名表

**输出**（`04-dependent-claims.md`）

- 从属权利要求列表（编号接续独权）
- 引用关系说明（结构待补）
- 未写入从权、仅拟放说明书的特征（如有）

## 上下游

- 上游：`write-independent-claim`（以及理解稿、命名表）
- 下游：`write-embodiments`、`write-specification-other`（实施例与发明内容需能支撑从权）

## 方法 / 结构

架构预留分支（规则待补）：方法从权（参数、附加步骤、工况等）与结构从权（材料、尺寸、连接变体、可选部件等）。

## 内容待补

- 从权分层与引用规则
- 单引 / 多引策略
- 与独权、命名表的一致性检查
