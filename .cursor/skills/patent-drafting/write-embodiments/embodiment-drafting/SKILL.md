# 说明书具体实施方式撰写

实施例要让人**顺着读懂这个东西长什么样、怎么装、怎么干活**，同时还能对上权利要求。对上权项靠复述段；读得清楚靠展开段。不要写成「权项原文 + 具体而言再翻译一遍权项」。

## 结构：对齐复述 + 讲清楚展开

每一条权利要求写两块，中间不要用套话硬接。

### 1. 复述段（对齐权项，不是给人读故事）

把该条权利要求的技术方案落到说明书里，作为与权项逐字对应的落脚点。

**可以删（不算改特征）：**「其特征在于」；从权的「根据权利要求X所述的……，」。其余特征措辞不要改。

**段首引导（只加在复述前，不要嵌进「一种」里）：**

| 场景 | 用 | 不要用 |
| --- | --- | --- |
| 独权、有图 | 「如图1至图3所示，」紧接「一种……包括……」 | 「在本实施例中，一种……」（介词短语不能直接管「一种装置」） |
| 独权、无图 | 直接从「一种……」起复述 | 「本实施例提供一种」再接「一种……」（一种会重复） |
| 从权 | 「如图X所示，」或「在上述基础上，」再接特征原文 | 「进一步地，所述……」连用多段；「根据权利要求X所述的……」 |

从权复述不要保留引用套话。特征原文若以「所述」开头，前面必须是「如图X所示，」或「在上述基础上，」，让「所述」有着落；不要单独一段以「所述」起句。

方法类：按步骤原文复述（S1、S2 等）。结构类：复述组成和连接，不要另编编号。

### 2. 展开段（给人读的，必须换一种写法）

复述完后**另起段落**写实施细节。按复述里特征出现的顺序写全，但句子要换成装配／工序叙述，补上位置、连接、谁带动谁、做到什么算完成。

**不要用「具体而言，」当展开段的固定开头。** 那是在给权项作注，不是在写实施例。只有复述特别长、不交代一下读者会对不上时，才可用一次「下面结合附图说明其具体结构。」之类，然后立刻进入部件。

展开段起句规则：

- **结构**：用「名称+标号」引出本段要讲的部件或部位，从整体到局部。例：「外罩1套在装置外侧。……风叶2装在外罩1的内壁上，……」
- **方法**：用时间／条件起句。例：「泄水洞3持续排水期间，先……。确认满足安全指标后，再……。」
- **从权展开**：只讲本条多出来的限定。例：「该夹角取 30°～60°。小于 30°时……大于 60°时……」不要再写一遍独权已讲过的外罩、风叶。
- **第一次出现**写「外罩1」，不要写「所述外罩1」。后文用「外罩1」即可，同一段内不要「所述」和光杆名称混着用。
- **禁止**展开段第一句是：「具体而言，」「进一步地，」「在本实施例中，」「所述XXX……」（该段尚未引出 XXX 时）

不能漏复述里的特征，也不能把复述没有的新特征写进主线。可选细节另段，用「作为一种可选方式，」——不要用「进一步地」冒充从权实施例。

### 两段分工

- 复述：权项口吻，短，不加标号、不加解释。
- 展开：说明书口吻，可分多段。每一段只推进一件事（一个部件或一步工序）。不要把五个部件塞进一句，也不要句句「用于……能够……」。作用写在动作后面：「……从而……」「……以免……」。

## 从权实施例

独权写完后，**每条从权都要有对应实施例**，仍是复述 + 展开，但：

1. 复述：引导语 + 特征原文（已删引用套话和「其特征在于」）。
2. 展开：只展开本条新增／进一步限定；已写过的用「如前所述」一句带过。
3. 数值、比例、角度：说明为何在此范围、越出上下限会怎样、范围内得到什么，不要只重复数字。
4. 连续多条从权不要每条都以「进一步地，」起句。可交替「如图X所示，」「在上述基础上，」「优选地，」或直接「名称+标号」。

## 附图

- 独权复述前用「如图X至图Y所示，」交代整体；局部在展开段就近写「见图3」。
- 标号只出现在展开段，格式「部件名称+标号」（外罩1），不要写成「1、外罩」。
- 标号、名称与命名表及附图说明一致，不编造。

## 不要写成宣传

展开可以说这个结构在运行里起什么作用，不要整段搬「有益效果」。实施例只负责公开和支持权项。

## 示范（注意起句）

**独权（结构）**

> 如图1至图3所示，一种喷雾降尘装置，包括外罩、风叶和降尘组件；所述风叶安装在所述外罩的内壁，能够转动以产生轴向气流；所述降尘组件设置在所述风叶的一侧，所述降尘组件包括环管和多个喷雾管；所述环管同轴设置在所述风叶的出风侧；多个所述喷雾管呈放射状固定连通于所述环管，每个所述喷雾管的管壁上开设有多个喷孔；所述喷孔的开口方向与所述风叶所在平面之间形成有夹角。
>
> 外罩1构成装置外壳。风叶2装在外罩1内壁上，由电机带动旋转，沿轴向推出气流，把后面喷出的雾滴送向前方。降尘组件位于风叶2出风一侧，由环管3和多根喷雾管4组成：环管3与风叶2同轴，接外部加压水并分到各喷雾管4；喷雾管4呈放射状接在环管3上，管壁开设喷孔5，水流由此雾化喷出。喷孔5的开口方向与风叶2所在平面成一夹角，雾滴同时受到水压和轴向风压，喷射距离比单靠水压更远。

不要写成：「在本实施例中，一种喷雾降尘装置……」「具体而言，外罩1的内壁安装有风叶2……」

**从权（参数）**

> 如图3所示，所述喷孔的开口方向与所述风叶所在平面之间的夹角为30°至60°。
>
> 该夹角落在 30°～60°。小于 30°时气流几乎平行于喷孔轴线，推力加不上；大于 60°时雾滴偏出主风场，射程反而缩短。

不要写成：「进一步地，所述喷孔……」「具体而言，所述夹角为30°至60°，该夹角……」

**方法步骤**

> 当所述地下水状态满足预设的安全指标时，对所述主洞隧道的围岩进行帷幕注浆；开挖所述主洞隧道，并施作衬砌；并在所述主洞隧道内施作中心水沟；其中，所述主洞隧道沿所述泄水洞平行施作，且所述主洞隧道的底面标高高于所述泄水洞的底面标高。
>
> 泄水洞3一边排水、一边超前探测时，同步监测主洞前方地下水。只有水位和压力稳定在预设安全指标以内，才开始后续开挖，避免带压作业引发涌水、突泥。
>
> 达标后，先在主洞1待挖段外围做帷幕注浆，形成阻水加固圈。注浆达到强度后，沿泄水洞3平行开挖主洞1，放样控制主洞底面始终高于泄水洞3底面，渗水可重力自流，不必在掌子面抽排。成型后施作衬砌，并在主洞底部纵向设置中心水沟2，收集衬砌后的残余渗水。

不要每一步都用「具体而言，」起段。

## 检查清单

- [ ] 复述是否对应该条权项全文特征，且已去掉「其特征在于」和从权引用套话？
- [ ] 有没有出现「在本实施例中，一种……」或「本实施例提供一种一种……」？
- [ ] 展开段是否未用「具体而言，」当默认首句？是否从名称+标号或工序动作起句？
- [ ] 有没有连续多段以「进一步地，」或「所述」开头？
- [ ] 展开是否按顺序覆盖复述中每个特征，且不是只给权项加了标号的复读？
- [ ] 从权展开是否只写新增限定？参数是否说明了上下限？
- [ ] 标号是否仅在展开段、格式为名称+标号、与命名表一致？
- [ ] 有没有把有益效果整段搬进实施例？

有新定义名词时，复述之后、展开之前按 `embodiment-term-first` 释义；释义段也不要用「具体而言，」起句。
