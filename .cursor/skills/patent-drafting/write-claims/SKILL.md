# 权利要求书撰写

接受 `conceive-independent-claim` 的第二版独权后，先命名，再落成完整权利要求书。独权构思决定**特征集合**；本 skill 决定**正式用名、独权主题架构、行文和从权**。不往核心独权里塞回已剔除的非必要特征。命名后含义变了，或缺必要特征补不回来，停写并回到独权构思。

规则编号 1–53 与「其中」的完整条文见 [references/claims-rules.md](references/claims-rules.md)。落笔和自检按编号执行；本文件是流程与必须遵守的用法。命名细则以 `name-components`（第5条）为准。

## 何时启用

- 独权构思第二版已完成，要写权利要求书或从权
- 无构思结果：先 `conceive-independent-claim`，不在此临编独权特征集

## 顺序（分步）

默认一轮一步。用户说一次写完除外。

1. **接受独权** → **立即**启用 `../name-components/`。无 `03-naming.md` 不得写权项正文。
2. **独立权利要求**：用正式名称改写；按 14–16、15、20 定主题与项数；套用思维模型；过一遍独权相关规则。
3. **从属权利要求**：关键创新点优先分层；详述型从权按 34、48。
4. **自检**：对照 [claims-rules.md](references/claims-rules.md) 逐条，改正后写入 `04-claims.md`。

不写说明书。权项中的结构、动作、功能、方法不得超出交底（含交底能合理读出的隐含内容）（38）。

## 独立权利要求

### 主题与项数（14、15、16）

具备新颖性的前提下，尽量从**包含改进的最小单元**起写，便于对上下游维权；需要时再增加更大主题的独权。

| 创新点落点 | 第一独权 | 第二独权 |
| --- | --- | --- |
| 装置 | 装置 | — |
| 单元 | 该单元 | 包含该单元的装置 |
| 部件且市场销量高 | 该部件 | 包含它的单元或装置 |
| 部件且销量很低 | 可直接以单元或装置为第一独权 | — |
| 仅结构 | 结构 | — |
| 仅方法 | 方法 | — |
| 结构+方法 | 结构 | 方法 |

构思稿若只给了一项较大主题的独权，本步可按上表**增加**独权项，不得改变核心区别对应的特征集合。额外独权可引用较小主题的权项（例如装置独权引用油封权项）。

主题上位（16）：发明人只做了一个产品，但概括到其他产品后仍有新颖性，才上位，且概括要准（自行车改进能到摩托车不能到汽车 → 两轮车，不要写成车辆）。不清楚能否用于其他产品时，**不要**上位主题，以免丧新。

主题用词（9、32、33、53）：

- 主题已清楚时，不要用能体现发明构思的词，除非发明人要求或开拓型发明
- 单元只有归属于装置时才写「用于装置的单元」；否则写「用于干什么的单元」（不要「用于工件的定位夹具」，写「用于对工件进行定位的夹具」）
- 「用于某某的功能单元」：某某取说明书会写到的最大层级（系统/设备/装置）
- 动宾定语：动词+宾语+的+被修饰词（排放油烟的装置），或宾语+动词+被修饰词（油烟排放装置）

使用环境（21、35、36）：「其特征在于」后第一个「包括」要有主语。夹具、工具、生产设备的创新常在使用环境或与被操作对象的配合，独权应写入。环境里有两个以上无归属关系的装置/单元/部件，优先出现在前序尤其是主题中。

方法权项（10、51）：单侧撰写，站在单一产品角度；对方作为使用环境。改进不在供电时，独权省略插头/电池/变压器等，放入从权。

核心发明点（24）：多项发明点时，新颖性有无 ＞ 商业价值 ＞ 安全系数 ＞ 重视程度 ＞ 撰写难易。不好交流时，选发明人认为有新颖性且最重视的。

### 思维模型（20、26、39）

保证新颖性的前提下，尽量站在**功能单元**写独权，避免写出单元内部件；改进不在单元内部件时，非发明点（尤其前序）更要用功能单元。与现有技术相同的特征尽量合并，越少越好（动力单元+传动单元 → 驱动单元）。

1. **功能单元**（常用于开拓型，如手工改自动）：装置包括用于做什么的功能单元1，以及与谁相连且用于做什么的功能单元2。功能单元上尽量不要写端部、侧部、进口、出口，留给其内部件。
2. **部件**（不好划单元时；改变型/增加型）：同上，把功能单元换成部件。
3. **混合**（最常用）：现有技术用功能单元，发明点用部件。

有使用环境时见 21。产品权项要分清内部动作与外部动作（人为操作）；除非为克服缺必特，不得用外部动作限定产品结构（23）。非结构特征（方法、功能、动作）必须对产品结构有限定作用，否则不用（22）。主语必须是产品或其内部单元/部件，不得以被加工对象或使用者为主语（47）。

「和/或」：独权所含每一技术方案都要有新颖性；仅「和」才新时不要用「或」（17）。

选定阈值须有取值范围、取值方法或用所要结果反向限定（11）。

## 从属权利要求

关键创新点按层次写入从权，不要塞回独权。

详述型从权（产品）（34、48、45）：写清待描述部件在哪些部件的哪些部位、如何连接（固定/可拆卸等）、实现什么功能；位置、连接、形状等结构特征不要漏。还要写这些部件与其他功能单元或其内部件的连接、位置、配合。

被引用权项里的功能单元若已有结构或功能限定，详述从权必须在**结构和功能两方面**都撑得住：用哪些部件、什么结构、什么位置和连接来实施该结构特征，并足以实现该功能。例如上位写单元1与单元2相连，从权至少写单元1中哪个部件与单元2相连、如何实现单元1的预期功能。

对功能单元进一步限定到部件后，应以该部件的角度写它与其他单元（或其部件）的连接和位置，避免重复限定或漏掉该部件的重要配合（28）。

## 行文通则（独权、从权都适用）

**特征（1、2）**  
不得缺必要技术特征（限定内容须足以实现预期功能）。不得含非必要特征（孤岛特征、删了也不影响解决问题的特征）。

**清楚（3、4）**  
用语、句子必须能确定保护范围。各项权项叠加后，与发明点关联的部件或单元要写到本领域技术人员熟知的有形程度。

**由已知引出未知（6）**  
- A（已知）包括 B（未知）  
- 在 A（已知）上设有 B（未知）  
- B（已知）与 A（已知）的 A1（未知）相连；A1 必须是现有技术且属使用环境特征  

**形状（7、8）**  
维度够：三维结构不要只用二维形状（圆柱不要只写成圆形）。有芯腔的环形不要写成没有芯腔的圆形。

**连接（18、19、42）**  
机械连接、传动连接、流体连接、电连接要直接或通过功能区分开。不同流体或信号要分开写（换热器的散热介质与吸热介质）。名称已用有形名词时，连接关系应有形化或动作化（套设、固定、可拆卸安装、可滑动地设置），除非该连接对任何方式都适用。

**虚实（29、40、41）**  
腔、流道、槽、孔等为虚结构；单元、部件、零件为实结构。不要写成虚实相连。加法：用包括、设有引出新实结构。减法：用包括、设有在实结构中引出新虚结构。

**层级（27、31、30）**  
一项权项尽量不要三级组成（装置包括单元、单元又包括部件），除非为上下文需要，并须符合 28。大小：系统＞设备＞装置＞单元＞部件＞构件＞详细结构；单元/组件/模块可自定义，模块通常一体成块，组件和单元不必。相同单元或部件若位置、连接或功能不同，用第一、第二区分。

**不要重复（37）**  
同一项内、有从属关系的各项之间，避免实质相同的文字。

**导向与凹凸（43、44）**  
八字形/锥形导向要限定大口朝向，保证沿由宽入窄进入。凹凸可互换位置时，写成「两者中的一个…另一个…」，不要钉死谁凹谁凸。

**参数（46）**  
为加热、烘干、反应环境等目的，温度、压力、时间等往往要在同一权项同时出现；必要时物质成分、材料等物理参数同时或提前出现。

**功能性特征（25）**  
仅当实施例充裕，或该功能能隐含结构时使用。

**实用新型产品权项（49、50）**  
可用已知方法限定结构，不可用新方法或旧方法里的详细步骤（参数值等）；非要出现步骤则尽量短。可用已知材料（铜、铁、铜铁合金），不可用已知材料的组分罗列（铜和铁）或未知材料。

### 标点（12、13）

除每项权利要求结尾外，其他地方不得句号。

冒号「：」用于「包括：」之后列出并列宾语。各分句用分号「；」分层。主语可在后续分句省略。分段与否不影响冒号规则。

例：一种装置，其特征在于，包括：A部件，关于A的描述；B部件，关于B的描述。

### 「其中」

需要对某个**已经出现的整体**的特定组成部分细化，或在马库什/多选里限定具体子集时才用。不要用「其中」引出尚未出现的新主题。

- 部件结构展开：大部件首次出现后，紧接着写其内部小结构。例：所述支撑组件包括第一杆体和第二杆体，其中所述第一杆体的一端与……连接。
- 步骤或参数细分：对前文某阶段或综合指标再指向。例：执行清洗步骤，其中所述清洗步骤的温度控制在 40℃ 至 60℃ 之间。
