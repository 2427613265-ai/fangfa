# 命名表：管道内壁修复结构

`write-claims` 已接受独权构思第二版。本表只换用名，不增删独权特征。权项与说明书同一套正式名称；交底原名后续禁止当正式名。

## 校核摘要

- 独权用名：主题「管道内壁修复结构」（方式 1）、修复衬层（方式 2）、支撑构件（方式 1）。未把方位词（方式 3）用作独权发明点名称。
- 「局部」留在特征「局部破损部位」，不放进主题，避免主题体现发明构思（权项规则 9）。特征集合未改。
- 不用「衬套」作独权名：套易被读成整周套管，与独权已概括的贴壁衬层不一致。从权/实施例仍称修复衬层，用层序限定。
- 缓冲层（衬层最内一层）与缓冲垫（支撑肋内侧）不同物，不同名。
- 卡扣、卡槽、填充膏、管道用领域通用名。

## 层级关系（写入权项时不要混级）

- 结构：管道内壁修复结构
  - 部件：修复衬层 → 树脂层 / 增强层 / 缓冲层
  - 构件：支撑构件 → 支撑肋、缓冲垫、锁紧件（卡扣、卡槽）
  - 部件：定位组件 → 定位边、弹性条、防滑凸起
  - 部件：密封组件 → 密封条、填充膏
- 环境：管道 → 管道内壁、破损部位、管内空腔
