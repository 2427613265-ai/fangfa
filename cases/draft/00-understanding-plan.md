## 名词解释

**单列一步。** 本案跨"地下工程 + 压缩空气储能热力学 + 过程控制"三个领域，专门名词密集且交底内部符号不统一，不先统一口径无法判断方案是否跑通。计划解释的词控制在下列范围（领域内极常见者不展开）：

- 储能侧：滑压运行、背压、级间换热、压比与等熵效率、绝热指数、再热、压缩因子（偏差因子）、末级压缩机
- 地下工程侧：既有废弃地下空间、洞室群分层布置、柔性抗裂混凝土衬砌、柔性密封层、围岩承载、气密性
- 监测控制侧：质量收支量 / 状态质量 / 质量残差、压差传感器矩阵与异常评价值、动态阈值、前馈—反馈复合控制、在线辨识、等效传热系数
- 交底内的别称并列：储气库 / 储气洞室；换热洞室 / 压缩换热洞室 / 释能换热洞室；换热介质 / 水 / 热水；循环泵 / 变频循环泵

## 技术方案拆法

**两者并用，先模块后流程。**

第一层按功能模块拆（交底自列 10 个子系统，合并同类后按 6 组讲）：

1. 地下压缩机系统（一级/二级/三级 + 末级，末级按背压增压）
2. 换热洞室系统（既有洞室改造、类管壳式、铜管+氧化铝涂层+翅片、衬砌作壳体边界）
3. 洞室结构与密封 + 安全监测定位系统（柔性抗裂衬砌、柔性密封层、应力计、压差传感器矩阵、质量残差判据、分级处置）
4. 储气系统 + 储热储冷系统（多库连通、水介质、储热罐/储冷罐、保温层）
5. 换热介质循环与补水系统（变频循环泵、流量/温度传感器、储水罐—补水泵—止回阀—调节阀—电磁阀）
6. 膨胀发电系统 + 释能热量分配控制（三级释能换热洞室、三级膨胀机、智能调节阀、滑压预测与分配系数）

其中 3、6 与自适应换热控制（属 2 与 5 的控制层）三段公式，逐式核对符号、量纲与因果闭环，并明确各式的输入来自哪个传感器、输出给哪个执行器。

第二层按流程串（放在第 5 步「整体工作流程」）：储能阶段 → 释能阶段 → 冷热循环闭合 → 构建施工步骤 1–6。

- **无任何工况参数**：储气压力等级、各级压比、进排气温度、储气库容积、储热温位、机组功率、循环水量等一概未给；具体实施方式中也没有一组数值实施例。
- **附图仅为方框示意**：图一只画出洞室分层与设备方框，空气管路与换热介质管路的走向、阀门位置、末级压缩机 7 与储气库 8/9/10 的连接、储气库与释能侧的接口均未在图上标注；交底自己也写明"高频温度传感器、应力计、压差传感器及智能调节阀在图中未逐一示出"。若定稿要用这两张图，附图需重画。
- **公式符号定义不全**：比焓 $h$ 的自变量与状态基准、$K_{T,i}$ 的物理含义与量纲、$\alpha_j$ 究竟乘在哪个量上、动态阈值与异常评价值 $S_j$ 的具体构造式、"膨胀机效率对入口温度的敏感程度"如何取值，交底均未写死；同一模型中气体常数一处写 $R_{air}$、一处写 $R$。

- **效果无量化、无对比文件**：有益效果全部为定性描述，没有试验或仿真数据，也未指明最接近的现有技术。
