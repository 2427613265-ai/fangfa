# 独权构思：供水管网压力表布设方法

用交底 / 理解稿用词，不做专利命名定稿。不把交底优选步骤直接当独权特征表。本轮完成步骤二（最小技术特征集）与步骤三（第一版独权）。

## 1. 核心区别技术特征与关键创新点

### 最接近手段（只据交底）

- 经验布点：按管网结构、漏损高发区、重要性主观选点。
- 聚类选点：按管网物理 / 水力特性分簇后抽代表点，不看定位模型内部表征。
- 全局增量（交底所称 SFFS 增量式方法）：以漏损定位误差为代价，在全网节点上逐点加入并可回溯，不先用模型内部特征压缩搜索空间。

发明人要站的边界：布点不再跟在水力聚类或全网增量后面，而是先读全节点 TCN 内部的节点表征，再只在由此得到的信息盲区里做增量选点。

### 核心区别（一句话）

用全节点 TCN 漏损定位基准模型最后卷积层的节点级特征向量划分特征簇，识别未被压力表覆盖的定位信息盲区，并仅在该信息盲区内按定位误差减少量动态增量选择压力表节点。

这句话看见的是一簇实现：聚类可以是谱聚类或其他相似度聚类；盲区贡献可以按“只用该簇”或“去掉该簇”来量化；增量可以是单层贪心或盲区级—节点级双层循环。不把谱聚类、余弦相似度、128 维、冗余回溯、EPANET 参数写进这一句。

**为何落在这条边界上：**

- 相对聚类选点：分簇对象是 TCN 最后卷积层的节点表征，不是管网物理量；选点不是“每簇装一块表”，而是在高贡献且无表覆盖的簇里按定位误差边际贡献加点。
- 相对 SFFS 全局增量：代价函数仍可以是定位误差，但候选空间被 TCN 特征簇定义的信息盲区约束，不再全网遍历。
- 不把“与 TCN 深度耦合”“全自动”“计算量降 84%”写进这一句：那是效果或口号。
- 不把双层循环的切换判据、每 K 点去冗余写进这一句：那是实现簇里的优选。

### 关键创新点（只登记，留给从权，不塞进独权）

| 点 | 为何巧 / 为何是特点 | 不进独权的理由 |
| --- | --- | --- |
| 余弦相似度矩阵 + 谱聚类 + 特征值法定簇数 | 交底划分特征簇的具体算法 | 核心是按 TCN 节点特征分簇，不锁死谱聚类 |
| 盲区级—节点级双层循环；盲区充分感知后再切换 | 交底搜索策略的层次 | 有信息盲区约束的增量已完整；外循环切换是效率优选 |
| 边际贡献衰减率、感知充分系数 | 背景里提出的切换判据 | 技术方案未给出可计算公式，不能当独权必要 |
| 每加入 K 个节点（K=1～5）做冗余回溯 | 控制表数、对应 SFFS 的后向扫描 | 优选；无此步方案仍能选出布设集合 |
| EPANET 全场景仿真及漏损面积 / 时段参数 | 数据从哪来 | 数据准备优选；独权只需有节点压力时序和漏损坐标 |
| 多尺度残差 TCN、最后一层 128 维 | 实施例网络结构 | 基准模型能出节点级卷积特征即可 |
| 单独再跑一遍水力仿真验证、输出安装优先级 | 工程收口 | 增量过程已用定位误差评估；清单格式是输出优选 |

## 2. 最小技术特征集

围绕第 1 步那句话，列出走完一遍布点所不可少的步骤及步骤间关系。类型是**方法**，一项独权。

一句话里需要说清楚的词：

- 「全节点 TCN 基准模型」：以全部节点压力时序为输入、以漏损点坐标为输出的时间卷积网络，用来取出每个节点的内部特征（交底称全节点 TCN 漏损定位基准模型）。
- 「节点级特征向量」：最后卷积层上每个节点对应的高维向量（交底实施例为 128 维；本步不锁维数）。
- 「特征簇」：按上述向量相似度把节点分成的组；同组表示对定位的信息贡献相近、存在冗余。
- 「信息盲区」：对定位误差影响更大、且当前压力表布设集合尚未覆盖的特征簇。
- 「当前压力表布设集合」：增量起点，可以是已有表位，也可以是空集（交底称既支持改造也支持从零）。
- 「动态增量」：只在信息盲区里按加入后定位误差减少量选点，每加入一点即按**当前表位**重训定位模型并更新剩余点的减少量。

### 特征表

| 编号 | 特征 | 为何必不可少 | 若不纳入，方案何处断裂 |
| --- | --- | --- | --- |
| F1 | 基于各节点压力时序及对应漏损坐标，训练全节点 TCN 基准模型（全节点时序入，漏损坐标出） | 没有全节点基准模型，就取不到未装表节点的内部表征，后续分簇无从做起 | 退回只在已有表位上训定位模型，无法为候选点提取 TCN 特征 |
| F2 | 提取该基准模型最后一个卷积层的节点级特征向量 | 核心区别的表征侧：分簇对象必须是模型内部节点特征 | 若改用压力原值或水力灵敏度，退回现有聚类选点 |
| F3 | 按节点级特征向量的相似度将节点划分为特征簇 | 把“模型看起来分不清”的节点收成组，才能定义盲区、压缩候选 | 没有簇，就没有“信息盲区”，后续只能全网增量 |
| F4 | 设定初始压力表布设集合作为当前压力表布设集合 | 增量必须有起点；覆盖关系也相对该集合而言 | “当前集合”“未被覆盖”没有着落 |
| F5 | 按各特征簇对漏损定位误差的影响，将贡献更大且未被当前集合覆盖的特征簇识别为信息盲区 | 核心区别的诊断侧：在 TCN 特征簇上找出无表且对定位更关键的区域 | 只有分簇没有盲区，会退化成每簇装表或仍在全网搜 |
| F6 | 仅在信息盲区内的节点中，选择加入后使全网平均定位误差减少量最大的节点加入当前集合 | 核心区别的搜索侧：候选空间被盲区约束，选择准则是定位误差减少量 | 若在全网选，退回 SFFS；若每簇固定代表点，退回聚类选点 |
| F7 | 用于计算上述平均定位误差的 TCN 定位模型，以当前集合中节点的压力时序为输入、以漏损点坐标为输出 | 表位必须进入模型输入，布点才对定位误差有意义；与 F1 的“全节点输入”不是同一个模型用法 | 若评估时仍用全节点输入，加表不改变输入，方案空转 |
| F8 | 每加入一个节点后，重新训练 F7 所述定位模型，并更新剩余节点的定位误差减少量，直至达到预设压力表数量或预设定位精度 | “动态”的含义：点与点的非线性协同要靠重训捕捉；方法还须有停止条件 | 不重训则是静态打分抽代表点；无停止条件则选点过程不闭合 |
| F9 | 输出当前压力表布设集合 | 布设方法须给出布设方案 | 走完增量却没有方案，构不成交底所称的布设方法 |

以上九条已经能构成：先用全节点 TCN 取出节点特征并分成特征簇，对照当前表位标出信息盲区，再只在盲区里按定位误差减少量动态加点，得到布设集合。实施时可以把聚类做成谱聚类、把增量做成双层循环、把数据做成 EPANET 全场景仿真，但那些不是本集合里的必要项。

不把“非线性时空响应模式”“深度耦合”“计算效率”写入：那是原理或效果，不是步骤。

## 3. 第一版独权

技术主题暂用交底对象（供水管网压力表布设方法），不把“基于 TCN 特征簇与动态增量优化”写进主题。正文只用第 2 步特征，连接语不夹带新限定。不用效果、原理、商业目的当特征。除权项结尾外不用句号。

### 正文

一种供水管网压力表布设方法，其特征在于，包括：基于目标供水管网各节点的压力时序数据及对应的漏损坐标，训练全节点时间卷积网络漏损定位基准模型，所述基准模型以全部节点的压力时序数据为输入、以漏损点坐标为输出；提取所述基准模型最后一个卷积层输出的节点级特征向量；根据所述节点级特征向量之间的相似度，将管网节点划分为若干特征簇；设定初始压力表布设集合作为当前压力表布设集合；根据各特征簇对漏损定位误差的影响，将相对于其他特征簇信息贡献更大且未被所述当前压力表布设集合覆盖的特征簇识别为信息盲区；在所述信息盲区内的节点中选择加入后使全网平均定位误差减少量最大的节点加入所述当前压力表布设集合，所述平均定位误差由以所述当前压力表布设集合中节点的压力时序数据为输入、以漏损点坐标为输出的时间卷积网络漏损定位模型得到，每加入一个节点后重新训练该漏损定位模型并更新剩余节点的定位误差减少量，重复选择直至达到预设的压力表数量或预设的定位精度；输出所述当前压力表布设集合。
