# 独权构思：市政雨污水管道非开挖快速修复加固结构

用交底 / 理解稿用词，不做专利命名定稿。不把理解稿「必要特征候选」直接当独权特征表。

## 1. 核心区别技术特征与关键创新点

### 最接近手段（只据交底与理解稿）

- 开挖换管：能换彻底，但对不上非开挖约束；不是结构上的近邻。
- CIPP 翻转内衬、紫外光固化：往旧管内做一层新衬，偏整段或长段。
- 点状注浆：对着漏点打浆，没有贴壁衬层骨架。
- **传统点状修复（交底当作最接近）**：只靠树脂固化层贴管壁，没有单独的内侧支撑，限位和边缘密封也弱。

发明人要站的边界：局部一个点坏了，既不做整段内衬，也不再「只贴一层胶」。

### 核心区别（一句话）

在管道内壁的局部破损部位设置贴合内壁的修复衬层，并在该衬层朝向管内空腔的一侧设置支撑构件。

这句话是抽象方案的出发点，不是实施例标题。看见的是一簇实现：衬层可以是复合片、树脂毡或其他贴壁层；支撑可以是肋、骨架、分片拼板，不必是交底那 3–6 组卡扣肋加硅胶垫块；「局部」相对整段内衬，不把形状锁死成某一种扇形裁片。

**为何落在这条边界上：**

- 相对整段内衬：限定在局部破损部位的修复衬层，不是把整条（或长段）管内再做一层。
- 相对点状注浆：有贴壁衬层，不是只灌浆。
- 相对「仅树脂贴壁」的点修：多了衬层内侧的支撑构件这一配合关系——区别在构件和位置，不在「抗沉降」这句话。
- 不把两端弹性定位、胶条加膏、三层材料、卡扣调管径写进这一句：那些是实现簇里的优选，写进去就只看见交底那一个点子。
- 不把「弧形、按破损裁切」写进这一句：那是衬层形状的一种；理解稿里补片 / 短段整周两种读法未钉死，核心区别落在「局部衬层 + 内侧支撑」，不落在必须扇形。

**立地说明（带着跑通问题）：** 作为结构关系，「衬层内侧有支撑构件」交底已公开，和「仅树脂贴壁」能分开。支撑能否把土压传到对侧或闭合成环，理解稿判定未闭合。核心区别只登记这一结构关系，**不把「已经能抗外压、抗沉降」写进一句话**。不补交底没有的胀圈、气囊。

### 关键创新点（只登记，留给从权，不塞进独权）

| 点 | 为何巧 / 为何是特点 | 不进独权的理由 |
| --- | --- | --- |
| 衬套两端弹性贴合定位（弧形定位边、伸缩弹性条、防滑凸起） | 对着「缺限位、易偏移」 | 是安装限位的优选结构，不是「内侧支撑」这条边界本身 |
| 外缘环形密封胶条 + 缝内防渗填充膏 | 对着「缺防渗」的半句 | 密封的具体两道做法，属优选 |
| 支撑做成若干弧形支撑肋，相邻肋用定位锁紧件可拆拼接 | 交底里支撑的具体形态，还想顺带调管径 | 支撑构件的一种实现；卡扣调 DN 未走通，更不能当独权必要 |
| 肋内侧弹性缓冲垫块 | 发明人强调缓冲沉降 | 优选零件；朝向空腔，传力存疑，不能当独权卖点 |
| 衬套三层一体复合（树脂固化层 / 玻纤网 / 橡胶缓冲层）及厚度 | 材料与层序 | 衬层的优选构造 |
| 衬套弧长按破损裁切、口头适配 DN300–DN1200 | 点状大小可变、管径口头覆盖 | 尺寸与适配的优选；尺寸链未写清 |
| 井下送入、常温固化的施工链 | 安装过程 | 方法性叙述；固化对象不明，结构独权不收 |

改进较小处（内侧要有支撑）与核心区别重合，上面其余各项是实施例上多出来的「巧」和「具体」，留给从权分层。

## 2. 最小技术特征集

围绕第 1 步那句话构造**完整方案**不可少的特征。不是按交底四条痛点把限位、双重密封、卡扣调径再堆回来。类型仍是**结构**，一项独权；安装流程不进本集合。

一句话里需要说清楚的词：

- 「修复衬层」：贴在破损内壁上的那一层修复体（交底称复合加固修复衬套 / 复合衬套；本步不上位成专利名）。
- 「支撑构件」：设在衬层朝管内一侧、与衬层一起工作的支撑件（交底称径向支撑加固组件，实施例是弧形支撑肋等；本步不锁成肋、垫块、卡扣三件套）。
- 「朝向管内空腔的一侧」：衬层背离管壁、朝管道中心的那一面，即交底说的衬套内侧。

### 特征表

| 特征 | 为何必不可少 | 若不纳入，方案何处断裂 |
| --- | --- | --- |
| 修复衬层设置在管道内壁的局部破损部位 | 没有「局部衬层」，对不上「不做整段内衬」；也没有贴壁修复体，和注浆分不开 | 变成整段内衬，或管内只有支撑没有修复层 |
| 修复衬层贴合该破损部位的内壁 | 衬层必须盖在破损内壁上才成其为管内贴补；这是位置/配合骨架，不是材料优选 | 衬层若悬空或贴在管外，不是本案修复结构 |
| 支撑构件设置在修复衬层朝向管内空腔的一侧 | 核心区别本身：和「仅树脂贴壁」的分界在这一侧的支撑 | 退回传统点状树脂贴壁，或支撑跑到管外（开挖侧） |
| 支撑构件与修复衬层相连接或相贴合，二者作为同一修复结构 | 没有连接/贴合，只是两个零件碰巧在管内，构不成一项完整结构 | 支撑托不住衬层，方案连不成一件装置 |

以上四条已经能构成：一块（或一层）贴在局部破损内壁上的修复衬层，其朝向管内的一侧连着支撑构件。实施时可以把衬层做成交底那种弧形复合片，把支撑做成若干肋，但那些不是本集合里的必要项。

不把「非开挖」「常温固化」「抗沉降」写入：前两者是安装方式或效果口号，后者理解稿已判定手段未闭合，不能当结构特征。

### 理解稿「必要特征候选」的剔除

理解稿 7.3 把交底四组件都放进独权候选池。本步按核心区别重切，剔除如下：

| 理解稿曾列为必要/骨架的 | 本步 | 原因 |
| --- | --- | --- |
| 弹性贴合定位组件对称设在衬套两端 | 剔除 | 关键创新点；没有它，衬层+内侧支撑仍是一件完整装置，只是安装时少了专用限位边 |
| 防渗密封组件包覆衬套外表面边缘 | 剔除 | 关键创新点；边缘胶条和膏是防渗优选，衬层贴壁本身已是一层覆盖 |
| 支撑必须包括弧形支撑肋 + 弹性缓冲垫块 + 定位锁紧件三件 | 剔除（收成「支撑构件」） | 三件套是支撑的优选形态；垫块朝空腔、卡扣调径未走通，更不能当完整性条件 |
| 相邻肋由定位锁紧件可拆卸固定 | 剔除 | 拼装方式优选 |
| 衬套必须是弧形柔性复合结构 | 剔除「弧形／复合／柔性」 | 「贴合内壁的局部修复衬层」已够完整；弧形、三层复合是形状和材料优选 |
| 四组件必须齐套 | 剔除 | 那是交底优选产品清单，不是围绕核心区别的最小完整方案 |

保留下来、并被说清楚的，只有：局部破损部位上的贴壁修复衬层，以及设在其管内侧并与之相连/贴合的支撑构件。

## 3. 第一版独权

技术主题暂用交底对象，步骤四再审定。正文只用第 2 步四条，连接语不夹带新限定。不用效果、原理、商业目的当特征。

### 正文

一种市政雨污水管道非开挖快速修复加固结构，其特征在于，包括修复衬层和支撑构件，所述修复衬层设置在管道内壁的局部破损部位并贴合所述内壁，所述支撑构件设置在所述修复衬层朝向管内空腔的一侧，且与所述修复衬层相连接或相贴合。

### 与最小特征集的对应

| 最小特征 | 正文中的落点 |
| --- | --- |
| 修复衬层设置在管道内壁的局部破损部位 | 「所述修复衬层设置在管道内壁的局部破损部位」 |
| 修复衬层贴合该破损部位的内壁 | 「并贴合所述内壁」 |
| 支撑构件设置在修复衬层朝向管内空腔的一侧 | 「所述支撑构件设置在所述修复衬层朝向管内空腔的一侧」——核心区别在此 |
| 支撑构件与修复衬层相连接或相贴合 | 「且与所述修复衬层相连接或相贴合」 |
| （骨架）二者同属一件结构 | 前序「包括修复衬层和支撑构件」 |

未写入正文的：弹性定位、密封胶条与填充膏、弧形/三层复合、支撑肋/垫块/卡扣、可拆卸、可裁切、管径范围、非开挖作为技术特征、常温固化、抗沉降或防渗效果。主题里的「市政雨污水」「非开挖快速修复加固」暂从交底名称带入，是否过窄留待步骤四。

## 4. 重核技术问题与技术主题

只按第一版实际包含的特征核定。不沿用交底「贴不稳、抗沉降、导流、快速抢修」那一整串。本轮不改写第二版全文，用词替换先点出。

### 4.1 第一版真正能对上的问题

第一版只有：局部破损内壁上的贴壁修复衬层，加上衬层朝向管内空腔一侧的支撑构件（与衬层连接或贴合）。

这套特征实际在做两件事：用局部衬层代替整段内衬；在衬层管内侧加上支撑，使点状修复不再只是一层贴壁树脂。

**核定后的技术问题：** 管道内壁仅局部破损时，整段内衬材料与工序浪费；现有点状修复仅以树脂层贴合管壁，修复衬层朝向管内空腔的一侧没有支撑构件。

不能再写成：提高抗外压抗沉降、杜绝脱空起鼓、适配 DN300–DN1200、缩短工期、非开挖快速抢修。那些要么靠已被剔除的限位/密封/卡扣，要么是效果口号，第一版撑不住。

### 4.2 与理解稿原问题的对照

理解稿原句：在不能开挖的城市管段上，对雨污水管的局部破损做原位修复时，整体内衬成本过高，现有点状修复难以贴稳管壁、也没有可靠的径向加固。

| 原问题里的成分 | 相对第一版 | 处理 |
| --- | --- | --- |
| 整体内衬对局部病害划不来 | 第一版有「局部破损部位的修复衬层」，对得上 | 保留，去掉「城市雨污水」「成本」等场景口号，改成材料与工序浪费 |
| 点修仅树脂贴壁、内侧无支撑 | 第一版有管内侧支撑构件，对得上 | 保留为问题的另一半；写成「没有支撑构件」，不写成「没有可靠径向加固」 |
| 难以贴稳管壁 | 第一版无定位组件 | 从独权问题里拿掉，留给从权 |
| 可靠径向加固 / 抗沉降 | 第一版只规定了支撑的位置，传力未闭合 | 不作为独权问题 |
| 不能开挖、城市雨污水 | 第一版结构特征不依赖这些 | 不写入独权问题 |

冲突处以第一版为准。

### 4.3 技术主题

交底主题：一种市政雨污水管道非开挖快速修复加固结构。本案按实用新型掌握主题宽窄。

第一版特征实际覆盖的是：装在**管道内壁局部破损处**的修复衬层及其管内侧支撑。不依赖雨水或污水介质，也不依赖「非开挖」「快速」这些安装/宣传用语。

- **过窄：** 「市政雨污水」把给水、工矿等圆管排除在外，而衬层贴内壁、内侧加支撑对圆管是同一结构；「非开挖」「快速」不是结构特征，「快速」更是效果词；「加固」容易被读成已经抗外压，与第一版能支撑的问题不匹配。
- **过宽：** 若收成「一种修复结构」或「一种衬层结构」，离开管道内壁就看不出对象，实用新型不宜这么空。
- **审定：** **一种管道内壁局部修复结构。** 仍扣在管道内壁、局部修复，与第一版四条特征同宽，不靠缩到市政雨污水来「增加创造性」。

### 4.4 留给第二版的用词（本轮不连缀全文）

- 前序主题改为：一种管道内壁局部修复结构。
- 正文里的「市政雨污水管道非开挖快速修复加固结构」与主题对齐替换。
- 「管道内壁的局部破损部位」「贴合所述内壁」「朝向管内空腔的一侧」「相连接或相贴合」四条特征暂不删；是否再上位（例如「相连接或相贴合」收成「设置于该侧并与衬层结合」）下一步再看，本轮不定稿。

## 5. 第二版独权

在核定后的技术问题与主题下回头看第一版。四条特征对新问题仍都必要，不删条；主题对齐，并把「相连接或相贴合」上位为「相结合」（覆盖连接、贴合、粘接、一体成型），不空到只剩口号。

### 核定后的技术问题

管道内壁仅局部破损时，整段内衬材料与工序浪费；现有点状修复仅以树脂层贴合管壁，修复衬层朝向管内空腔的一侧没有支撑构件。

### 核定后的技术主题

一种管道内壁局部修复结构。

### 第二版正文

一种管道内壁局部修复结构，其特征在于，包括修复衬层和支撑构件，所述修复衬层设置在管道内壁的局部破损部位并贴合所述内壁，所述支撑构件设置在所述修复衬层朝向管内空腔的一侧，并与所述修复衬层相结合。

### 相对第一版的删减 / 上位

| 第一版 | 第二版 | 处理 |
| --- | --- | --- |
| 一种市政雨污水管道非开挖快速修复加固结构 | 一种管道内壁局部修复结构 | 上位主题：去掉市政雨污水、非开挖、快速、加固 |
| 包括修复衬层和支撑构件 | 同左 | 保留 |
| 设置在管道内壁的局部破损部位 | 同左 | 保留：没有「局部」就对不上整段内衬浪费 |
| 并贴合所述内壁 | 同左 | 保留：没有贴壁就不是衬层贴补，和注浆分不开 |
| 设置在……朝向管内空腔的一侧 | 同左 | 保留：核心区别，不能再抽象成「具有支撑」 |
| 且与所述修复衬层相连接或相贴合 | 并与所述修复衬层相结合 | 上位：结合包含连接、贴合、粘接、一体成型 |
| （未写入的定位、密封、肋垫块卡扣等） | 仍不写入 | 无变化 |

立地：仍是可贴到局部破损内壁上的衬层，其管内侧结合有支撑构件，交底的复合衬套加内侧肋是实现方式之一。核心区别边界仍在：相对整段内衬有「局部」，相对仅树脂贴壁有「管内侧支撑」。不把抗沉降、非开挖写成特征。

### 是否还合适（逐条）

新问题只问两件事：局部对整段、管内侧有没有支撑。弹性定位、边缘密封、三层材料、卡扣调径都不回答这两句，不加回来。「相结合」没有把方案抽成纯效果。

## 6. 下游指针

本文件第二版是交给 `write-claims` 的独权构思结果。用户认可第二版后，才算独权构思完成；正式专利用名由 `write-claims` 接手后先做 `name-components`。

**留给从权的关键创新点（不写从权文句）：**

- 衬套两端弹性贴合定位（弧形定位边、伸缩弹性条、防滑凸起）
- 外缘环形密封胶条 + 缝内防渗填充膏
- 支撑做成若干弧形支撑肋，相邻肋用定位锁紧件可拆拼接
- 肋内侧弹性缓冲垫块
- 衬套三层一体复合（树脂固化层 / 玻纤网 / 橡胶缓冲层）及厚度参数
- 衬套弧长按破损裁切；口头适配 DN300–DN1200

**未进独权的其他优选：** 井下送入与常温固化施工链（方法性）；实施例 DN600、4 组肋。

**不要写进权项当效果特征：** 抗外压抗沉降已实现、工期缩短 30%、杜绝脱空起鼓、导流、塌陷复位。

用词仍是交底/理解用词（修复衬层、支撑构件），不是专利命名定稿。
