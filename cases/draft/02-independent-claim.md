# 独权构思：市政雨污水管道非开挖快速修复加固结构

用交底 / 理解稿用词，不做专利命名定稿。不把理解稿「必要特征候选」直接当独权特征表。

## 1. 核心区别技术特征与关键创新点

### 最接近手段（只据交底与理解稿）

- 开挖换管：能换彻底，但对不上非开挖约束；不是结构上的近邻。
- CIPP 翻转内衬、紫外光固化：往旧管内做一层新衬，偏整段或长段。
- 点状注浆：对着漏点打浆，没有贴壁衬层骨架。
- **传统点状修复（交底当作最接近）**：只靠树脂固化层贴管壁，没有单独的内侧支撑，限位和边缘密封也弱。

发明人要站的边界：局部一个点坏了，既不做整段内衬，也不再「只贴一层胶」。

### 核心区别（一句话）

在管道内壁的局部破损部位设置贴合内壁的修复衬层，并在该衬层朝向管内空腔的一侧设置支撑构件。

这句话是抽象方案的出发点，不是实施例标题。看见的是一簇实现：衬层可以是复合片、树脂毡或其他贴壁层；支撑可以是肋、骨架、分片拼板，不必是交底那 3–6 组卡扣肋加硅胶垫块；「局部」相对整段内衬，不把形状锁死成某一种扇形裁片。

**为何落在这条边界上：**

- 相对整段内衬：限定在局部破损部位的修复衬层，不是把整条（或长段）管内再做一层。
- 相对点状注浆：有贴壁衬层，不是只灌浆。
- 相对「仅树脂贴壁」的点修：多了衬层内侧的支撑构件这一配合关系——区别在构件和位置，不在「抗沉降」这句话。
- 不把两端弹性定位、胶条加膏、三层材料、卡扣调管径写进这一句：那些是实现簇里的优选，写进去就只看见交底那一个点子。
- 不把「弧形、按破损裁切」写进这一句：那是衬层形状的一种；理解稿里补片 / 短段整周两种读法未钉死，核心区别落在「局部衬层 + 内侧支撑」，不落在必须扇形。

**立地说明（带着跑通问题）：** 作为结构关系，「衬层内侧有支撑构件」交底已公开，和「仅树脂贴壁」能分开。支撑能否把土压传到对侧或闭合成环，理解稿判定未闭合。核心区别只登记这一结构关系，**不把「已经能抗外压、抗沉降」写进一句话**。不补交底没有的胀圈、气囊。

### 关键创新点（只登记，留给从权，不塞进独权）

| 点 | 为何巧 / 为何是特点 | 不进独权的理由 |
| --- | --- | --- |
| 衬套两端弹性贴合定位（弧形定位边、伸缩弹性条、防滑凸起） | 对着「缺限位、易偏移」 | 是安装限位的优选结构，不是「内侧支撑」这条边界本身 |
| 外缘环形密封胶条 + 缝内防渗填充膏 | 对着「缺防渗」的半句 | 密封的具体两道做法，属优选 |
| 支撑做成若干弧形支撑肋，相邻肋用定位锁紧件可拆拼接 | 交底里支撑的具体形态，还想顺带调管径 | 支撑构件的一种实现；卡扣调 DN 未走通，更不能当独权必要 |
| 肋内侧弹性缓冲垫块 | 发明人强调缓冲沉降 | 优选零件；朝向空腔，传力存疑，不能当独权卖点 |
| 衬套三层一体复合（树脂固化层 / 玻纤网 / 橡胶缓冲层）及厚度 | 材料与层序 | 衬层的优选构造 |
| 衬套弧长按破损裁切、口头适配 DN300–DN1200 | 点状大小可变、管径口头覆盖 | 尺寸与适配的优选；尺寸链未写清 |
| 井下送入、常温固化的施工链 | 安装过程 | 方法性叙述；固化对象不明，结构独权不收 |

改进较小处（内侧要有支撑）与核心区别重合，上面其余各项是实施例上多出来的「巧」和「具体」，留给从权分层。
