# 独权构思：一种热处理冷矫直机后的圆盘除尘装置

用交底 / 理解稿用词，不做专利命名定稿。不把理解稿「必要特征候选」直接当独权特征表。

## 1. 核心区别技术特征与关键创新点

### 最接近手段（只据交底与理解稿）

- 高压水冲洗：能把氧化铁皮冲掉，但是带水的，后面要烘干、污水要处理。和本案不在同一条「干式刮扫」路上，不是结构上的近邻。
- **毛刷辊清扫（交底当作冷矫直后常用干式手段，结构上的近邻）**：单根或两根平行毛刷辊，辊轴线沿板宽、圆柱刷面扫过钢板。交底指出有条带状/边部盲区、高度不好调、粉尘扩散。

发明人要站的边界：冷矫直之后仍让钢板沿辊道通过，但不再用平行毛刷辊去扫，也不改回水洗。

### 核心区别（一句话）

在冷矫直机出口辊道的上方，用沿辊道宽度方向布置、并沿运行方向前后错开的多组清扫圆盘，清除钢板表面的氧化铁皮。

这句话是抽象方案的出发点，不是实施例标题。看见的是一簇实现：圆盘可以是三前两后，也可以是两前一后、四前三后，只要前后错开把板宽上的漏扫条带补上；刷可以是钢丝刷或其他清扫刷；各盘可以各自有电机，也可以用别的传动把圆盘转起来；盘径、重叠量不必锁成 300–500 mm 和 50–100 mm。

**为何落在这条边界上：**

- 相对毛刷辊：工作件从「平行圆柱刷辊」换成「多组清扫圆盘」，布置从「沿板宽一根或两根平行」换成「沿板宽排开、前后错开补缝」。区别在构件和位置关系，不在「清洁度 98%」这句话。
- 相对高压水冲洗：是干式圆盘刮扫，不是水冲。一句话里不必再写「无水」，写了清扫圆盘就已经站在水洗的另一侧。
- 不把五组、前 3 后 2 写进这一句：那是交叉错位里的一种数量和排法；写进去就只看见交底那一个点子。
- 不把液压升降、四角油缸写进这一句：那是迁就板厚的优选；毛刷辊交底已说「高度调节不便」，说明调高本身不是本案才有的构件类型，本案的特别处首先不在「有升降」。
- 不把整体式除尘罩、柔性帘、风机、烟囱写进这一句：那是刮起来的粉尘往哪走的优选；没有罩，圆盘仍能在矫直后把皮扫下来，只是车间扬尘那条痛点还在。核心区别先落在「怎么扫」，不落在「灰如何抽走」。
- 不把电机装在框架顶、减速器、传动轴、钢丝刷写进这一句：那是单组传动链和刷材的优选。

**立地说明：** 作为结构关系，「辊道上方、多组清扫圆盘、沿板宽布置并前后错开」交底已公开（实施例落实为前 3 后 2 加边缘重叠），和平行毛刷辊能分开。不把「已经扫到 98%、已经适应 6–50 mm、已经无二次污染」写进一句话。不补交底没有的下表面清扫、收尘器。

### 关键创新点（只登记，留给从权，不塞进独权）

| 点 | 为何巧 / 为何是特点 | 不进独权的理由 |
| --- | --- | --- |
| 五组、前排三组中心连线垂直于运行方向、后排两组落在前排间隙正后方 | 交底里交叉错位的具体排法，直接对着毛刷辊盲区 | 是「前后错开补缝」的一种实现，不是边界本身 |
| 相邻圆盘边缘重叠 50–100 mm、盘径 300–500 mm | 把补缝做成带宽重叠，给出尺寸窗 | 参数与实施例；没有数字，前后错开仍能构成方案 |
| 液压升降机构、四缸同步、缸体在基础、活塞杆铰接框架 | 对着「不同板厚调高不便」 | 调高是附加能力；锁成液压四角会把丝杆、气缸等实现踢出去 |
| 整体式除尘罩罩住全部圆盘，接到除尘风机和烟囱 | 对着粉尘扩散；名称里的「除尘」也容易让人想写进独权 | 是收尘侧优选；核心区别在圆盘怎么扫，不是灰怎么排 |
| 柔性密封帘、下缘离辊道 50–100 mm | 罩的底部封法 | 密封细节；理解稿还指出与整体升降的间隙未写清 |
| 罩内倾斜导流板、进风管风量调节阀 | 流场与风量微调 | 排风系统内部件，改进较小 |
| 每组独立驱动电机，可单独调转速 | 发明人强调效率和能耗 | 圆盘转起来即可；分电机调速是驱动方式的优选 |
| 耐磨钢丝刷 | 刷材 | 清扫刷的一种 |
| 电机在框架顶部、减速器、传动轴连盘心 | 单组传动链 | 把扭矩传到圆盘即可，不必锁这条链 |

改进较小处（用圆盘而且前后错开）与核心区别重合。上面其余各项是实施例上多出来的「巧」和「具体」，留给从权分层。

## 2. 最小技术特征集

围绕第 1 步那句话，列出能构成该装置的最少部件及必要连接、位置。类型是**结构**，一项独权。

一句话里需要说清楚的词：

- 「出口辊道的上方」：装置的使用环境，圆盘从钢板走过的那一侧靠近上表面；出口辊道本身不是装置的零件。
- 「多组清扫圆盘」：交底称圆盘清扫机构，每组有一个清扫圆盘；组数不锁成五。
- 「沿辊道宽度方向布置」：沿板宽排开，不是只在板中心前后串成一列。
- 「沿运行方向前后错开」：分成前排和后排；前排沿板宽留出间隙，后排落在这些间隙的后方，用来补前排没扫到的条带。不锁成前 3 后 2，也不把重叠毫米数写进来。
- 「清除氧化铁皮」：落实为结构，不是效果句——清扫圆盘朝向辊道的一侧有清扫刷，并由驱动装置带着转。刷材不锁成钢丝刷；几组盘可以共用一套驱动，不必每组一台电机。

交底实施例里的架子叫升降框架。本集合只要一个能把圆盘保持在辊道上方、并维持前后错开位置的**框架**；不要求它能升降。

### 特征表

| 编号 | 特征 | 为何必不可少 | 若不纳入，方案何处断裂 |
| --- | --- | --- | --- |
| F1 | 装置用于设置在冷矫直机出口辊道的上方 | 核心区别的位置。没有这条，圆盘清扫可以出现在开卷、横切、库内等任意场合，不再是矫直后在线刮扫 | 退回一般盘刷除鳞，和交底要改的「冷矫直机后」对不上 |
| F2 | 设有框架，作为多组圆盘清扫机构的安装主体 | 骨架。没有安装主体，多组圆盘无法保持既定的板宽排布和前后错位 | 只剩「一堆圆盘在辊道上方」，位置关系说不稳 |
| F3 | 多组圆盘清扫机构安装在框架上，并位于框架朝向出口辊道的一侧 | 把刷面放到钢板走过的那一侧（交底是框架底部） | 圆盘若在框架外侧或辊道下方，不是交底这条过钢路径 |
| F4 | 每组圆盘清扫机构包括清扫圆盘；清扫圆盘朝向出口辊道的一侧设有清扫刷 | 刮氧化铁皮的工作件。交底没有给出无刷圆盘、刮刀盘等另一种刮法 | 只写「圆盘」时，接触钢板的可以是光面或磨片，方案从清扫变成未公开的别的除鳞 |
| F5 | 设有驱动装置，驱动装置与清扫圆盘传动连接，带动清扫圆盘转动 | 交底的清扫是旋转刮扫。驱动可以是一台分到多盘，也可以每盘一台，本步不锁 | 不转则退回随动拖刷或静压，不是圆盘清扫机构 |
| F6 | 所述多组圆盘清扫机构沿辊道宽度方向排布 | 对着板宽覆盖。没有沿板宽排开，前后错开也只扫一条窄带 | 退回中心线上前后两个盘，边部完全不扫，对不上毛刷辊那条「板宽方向的盲区」 |
| F7 | 所述多组圆盘清扫机构沿辊道运行方向分为前排和后排；前排沿辊道宽度方向间隔布置；后排位于前排相邻圆盘清扫机构之间间隙的后方 | 把「前后错开」写成位置关系：后排补前排缝。这是核心区别在结构上的落点 | 若多盘并成一排，要么盘体/驱动互相干涉留缝，要么变成一排圆盘，交叉补缝这条边界消失 |

以上七条已经能构成：在矫直机出口辊道上方用框架托住多组带刷圆盘，驱动它们旋转，沿板宽排开，并以前后两排把前排间隙补上。实施时可以把框架做成升降框架、把排法做成前 3 后 2、给每盘独立电机、再扣上除尘罩，那些不是本集合里的必要项。

不把「无盲区」「清洁度 98%」「干式无水」写入：那是效果，不是部件或位置。

### 从完整方案里剔除、不进本集合的

| 理解稿或交底里看起来像必要的 | 本步 | 原因 |
| --- | --- | --- |

## 3. 第一版独权

技术主题暂用交底对象（一种热处理冷矫直机后的圆盘除尘装置），步骤四再审定。正文只用第 2 步七条，连接语不夹带新限定。不用效果、原理、商业目的当特征。除权项结尾外不用句号。

### 正文

一种热处理冷矫直机后的圆盘除尘装置，用于设置在冷矫直机出口辊道的上方，其特征在于，包括框架、多组圆盘清扫机构和驱动装置，所述多组圆盘清扫机构安装在所述框架上且位于所述框架朝向所述出口辊道的一侧，所述多组圆盘清扫机构沿辊道宽度方向排布并沿辊道运行方向分为前排和后排，所述前排沿辊道宽度方向间隔布置，所述后排位于前排相邻圆盘清扫机构之间间隙的后方，每组圆盘清扫机构包括清扫圆盘，所述清扫圆盘朝向所述出口辊道的一侧设有清扫刷，所述驱动装置与所述清扫圆盘传动连接，以带动所述清扫圆盘转动。
