# 理解稿：一种热处理冷矫直机后的圆盘除尘装置

交底来源：技术交底书《一种热处理冷矫直机后的圆盘除尘装置》。申请类型勾选实用新型。理解阶段用交底用词，不写权利要求、不定专利命名。对比手段只取交底所写，不引入另行检索的对比文件。

## 1. 跑通检查

**结论：可跑通，附次要瑕疵与若干存疑。不构成硬伤停步。**

按交底，钢板从热处理冷矫直机出来，走出口辊道；辊道上方一座可升降的框架，底下挂多组带钢丝刷的清扫圆盘，上面扣整体式除尘罩，风机把扬尘抽到烟囱。板厚变了就整架升降，圆盘按前排间隔、后排补缝的方式扫过上表面。这条主路径在结构上能装上、在工序上能走完。

### 1.1 主路径可以走完

- **交底原文**：升降框架架在出口辊道上方；五组圆盘清扫机构装在框架底部，前 3 后 2 交叉错位；液压升降调高度；整体式除尘罩罩住全部圆盘；风机进风口接罩顶出风口，出风口接烟囱。
- 钢板在辊道上前行 → 圆盘下表面钢丝刷接触上表面旋转刮扫 → 氧化铁皮被刷下并扬起 → 罩内导流、风机抽走。液压把框架连同圆盘一起升高或降低，以迁就不同板厚。
- **标记**：上述为交底原文。圆盘相对辊道的压下量、转速与线速度如何匹配，交底未写；缺这些参数仍可把装置装起来并转动，只是工况要现场整定。

### 1.2 密封帘与整体升降的间隙（存疑，非硬伤）

- **交底原文**：柔性密封帘下边缘距离辊道上表面 50–100 mm；液压升降按板厚调节清扫圆盘高度，适应 6–50 mm。
- **错在哪里**：帘、罩、圆盘都在同一升降框架上。框架升高时，若帘长固定，帘下缘到辊道的距离会变大；板厚 50 mm 而帘下缘只离辊道 50 mm 时，板头还可能蹭帘。
- **会怎样卡住**：不一定装不上，但「50–100 mm」不能同时当作与辊道的固定安装尺寸和与任意板厚都成立的过钢间隙。
- **标记**：尺寸与同架升降为交底原文；帘是否有余长、是否随板厚另调，为交底未写。合理推断：柔性帘可以做得较长，下缘仍能落到辊道附近，但交底没写。

### 1.3 只扫上表面（交底范围，不是自相矛盾）

- **交底原文**：装置在辊道上方；清扫圆盘下表面装刷；效果写钢板表面清洁度。
- 下表面、侧面立面的清扫件交底未写。主路径不因此断开，只是保护对象应理解为上表面清扫。
- **标记**：下表面清扫为交底未写。

### 1.4 排风只有风机和烟囱（次要）

- **交底原文**：除尘排风系统包括除尘风机和烟囱。
- 交底未写袋式、旋风等收尘器。装置仍能把粉尘从罩内抽走并排出；是否达标排放是环保问题，不是本机转不起来的问题。
- **标记**：收尘器为交底未写。

### 1.5 电机位置：文字与附图不完全一致（次要）

- **交底原文**：驱动电机固定在升降框架顶部，经减速器、传动轴连到清扫圆盘中心。
- **附图（交底所附三维图）**：各圆盘上方斜向支座上各自有电机，图面标号与正文零件号对不上，图上有生成水印。
- **会怎样卡住**：两种布置都能把扭矩传到圆盘，不导致方案装不上。理解以文字传动链为准，附图只证明「每盘有驱动、五盘分前后排」。
- **标记**：传动链为交底原文；图号错乱、渲染图不符合交底模板附图要求，属材料缺口。

### 1.6 独立调速缺少控制描述（次要）

- **交底原文**：每组独立驱动，可按氧化铁皮附着情况单独调节转速。
- 交底未写检测手段和调节逻辑。有独立电机就可以人工或变频器分别调，路径不断。
- **标记**：调速策略为交底未写。

### 1.7 按交底走一遍

冷矫直出口上料 → 按板厚升降框架 → 圆盘旋转、钢板在辊道上穿过刷面 → 前排扫过大部分板宽，后排补前排间隙 → 罩内粉尘被抽走。断点只出现在帘隙与板厚的定量关系、下表面是否清扫、收尘器有无——都不阻止这套上方干式圆盘清扫机运转。

## 2. 名词解释

领域专门名词不多，但有几个交底里的词需要先对齐，避免后面把「除尘」理解成环保收尘、把「交叉错位」理解成任意斜摆。

### 冷矫直机、出口辊道

热处理后的钢板要在常温附近矫平。冷矫直机就是做这件事的设备。出口辊道是矫直机后面一排输送辊，钢板从这里离开矫直机、进入下游。本案装在这排辊的**上方**。

### 氧化铁皮

热处理加热、淬火、回火时钢板表面生成的氧化层。交底说矫直会磕掉一部分，仍有大量附着。本案要清的就是这层皮，清下来以后成为粉尘。

### 毛刷辊清扫

交底所列现有手段之一：一根或两根与板宽方向平行的圆柱刷辊，辊面刷毛扫过钢板。交底批评它有清扫盲区（尤其边部和边角）、高度不好调、粉尘扩散。

### 高压水冲洗

交底所列另一现有手段：用水冲氧化铁皮。交底批评水渍、烘干、污水。

### 圆盘清扫机构、清扫圆盘、清扫刷

一组驱动把一个圆盘带着转，圆盘朝向钢板的一面装刷（交底实施例是耐磨钢丝刷）。刷面近似水平，轴线近似竖直。和毛刷辊的差别：毛刷辊是横着的圆柱面扫过去；圆盘是圆平面在板面上转。

### 前 3 后 2、交叉错位

交底的优选布置：沿板宽先排三个圆盘，中心连线垂直于辊道运行方向，彼此有间隙；后面再排两个，分别落在前排相邻两盘之间那条缝的正后方。交底总述里也说「交叉布置」。重叠量写的是相邻圆盘边缘重叠 50–100 mm，所以后排不是只「对着缝看看」，而是扫过的带宽要盖住前排没扫到的那条带。

### 升降框架、液压升降机构

一座架子把所有圆盘和除尘罩吊在辊道上方。四角液压缸、同步阀，整架升高或降低。交底用它适应 6–50 mm 板厚。

### 整体式除尘罩、柔性密封帘、除尘排风系统

一个罩把全部圆盘罩住，不是每盘一个小罩。底部四周挂柔性帘，交底给了帘下缘离辊道 50–100 mm。排风系统在交底里就是风机加烟囱，罩顶出风口接到风机。罩内还有倾斜导流板。这里的「除尘」同时有两层意思：把氧化铁皮从钢板上扫下来，以及把扬尘抽走不让它在车间扩散。

## 3. 技术问题

### 场景与约束

热处理钢板生产线。钢板已经过加热、淬火、回火，表面有坚硬氧化铁皮；刚出冷矫直机，部分皮已脱落，仍有大量附着。若不及时清，交底说会影响表面质量，并在后续运输、剪切、加工中磨损设备和造成产品缺陷。装置必须让钢板在辊道上连续通过，不能改成水洗后还要烘干的那套。

### 现有做法 / 最接近的常规手段（只据交底）

1. **高压水冲洗**：除尘效果较好，但有水渍，要加烘干，污水要处理。
2. **毛刷辊清扫**（单根或两根平行毛刷辊）：干式，更接近本案；交底指出清扫盲区（边部、边角不彻底）、高度调节不便、粉尘扩散到车间。

结构上的近邻是毛刷辊，不是水洗。水洗的主要反差是「带水」；毛刷辊的主要反差是「怎么扫」和「灰往哪去」。

### 缺陷（尽量能被后文手段对上）

| 现有做法 | 交底指出的缺陷 |
| --- | --- |
| 高压水冲洗 | 水渍、烘干能耗、污水处理 / 二次污染 |
| 毛刷辊 | 盲区，边部边角不彻底 |
| 毛刷辊 | 高度调节不便，难适应不同板厚 |
| 毛刷辊 | 粉尘扩散，污染作业环境 |

### 本发明针对的核心问题（一句话）

冷矫直之后，要在钢板仍沿辊道前行的条件下，把上表面氧化铁皮干式清掉，并且尽量扫全、少留条带状漏扫。

水渍、二次污染、粉尘外逸、板厚变化，是交底并列提出的痛点；核心问题先落在「干式、连续通过、扫全」。其余痛点由罩、升降等手段分别对着，不把四件事捆成一个问题，以免后面理解方案时把所有优选都当成同一问题的唯一解。

## 4. 技术方案（按功能模块）

发明类型：**结构**。没有单独的新方法步骤。按模块拆，用交底用词。

### 4.1 安装位置与升降框架

升降框架架在冷矫直机出口辊道上方，四角通过液压升降机构与地面基础相连。液压升降机构包括四个液压缸和同步控制阀：缸体在基础上，活塞杆顶端与框架底部铰接，四缸同步升降。作用：整架带着圆盘改变相对辊道的高度，交底用来适应 6–50 mm 板厚。

优选 / 附加：必须液压、必须四角、必须与地面基础相连——这是交底实施例。电动丝杆、气缸、不是四角布置，交底未写，此处不补成已公开。

### 4.2 圆盘清扫机构（清扫模块）

五组圆盘清扫机构固定在升降框架底部。布置：前排三组，中心连线与辊道运行方向垂直；后排两组，分别位于前排相邻两组的正后方间隙处。每组：驱动电机（交底写在框架顶部）→ 减速器 → 传动轴 → 清扫圆盘中心；圆盘下表面为耐磨钢丝刷。盘径 300–500 mm，相邻圆盘边缘重叠 50–100 mm。每组独立驱动，交底说可按附着情况单独调转速。

这是对着毛刷辊盲区的手段：圆盘分前后排，后排补前排缝，再用重叠把带宽接上。

必要手段与优选要分开记：

- **清扫作用靠旋转圆盘上的刷去刮钢板**——没有它就不是这套圆盘方案。
- **多组、沿板宽排、前后错开补缝**——交底用来消灭条带漏扫；五组、前 3 后 2、盘径和重叠量的数字是优选。
- **每组一台电机**——交底当作独立调速的前提；若多盘由一台电机分路传动，交底未写，不当成已公开的唯一结构。

### 4.3 整体式除尘罩与排风

整体式除尘罩固定在升降框架顶部，完全罩住所有圆盘清扫机构。底部四周柔性密封帘。罩内顶部倾斜导流板，把粉尘导向顶部出风口。除尘风机进风口经管道接该出风口，出风口接烟囱；进风管道上有风量调节阀。

作用：把刮起来的氧化铁皮粉尘关在罩里抽走，对着毛刷辊的粉尘扩散。相对水洗，整条清扫链是干的。

优选：导流板、风量阀、烟囱、帘的 50–100 mm。罩住全部圆盘并接到排风，是交底完整方案里的收尘侧；没有罩，圆盘仍能扫，只是车间扬尘问题交底认为没解决。

### 4.4 模块之间怎么连

辊道在下（使用环境，不是必须画进装置本体）。框架在上，圆盘挂在框架底，罩在框架上（交底写顶部）把圆盘罩住。升降一动，圆盘和罩一起动。粉尘路径：刷面 → 罩腔 → 出风口 → 风机 → 烟囱。

附图能看出五盘分前后、右侧箱体加风机烟囱、左侧立缸，但标号体系与正文（1、2、3、4、5、6、7、21–25、31、32、51、52、61）对不上，细节图、局部放大交底未提供。

## 5. 整体工作流程

起始：热处理后的钢板完成冷矫直，沿出口辊道进入本装置下方。框架已按该批板厚升降到位，圆盘下的刷接触或压在上表面上（压下量交底未量化）。

中间：驱动电机带动各清扫圆盘旋转。钢板继续前行。前排三个圆盘先扫过各自带宽，带宽之间留有间隙；钢板再走到后排，两个圆盘扫过那些间隙对应的条带。相邻圆盘边缘有重叠，交底用来避免漏扫。刮下的氧化铁皮在罩内扬起，导流板把气流导向顶部出风口，风机抽吸，经烟囱排出。风量可用阀调。某组氧化铁皮特别厚时，交底设想单独加那一组的转速。

结束：钢板带着被扫过的上表面离开罩区，进入后续运输、剪切、加工。框架不必每张板都动，换规格再升降。

人：交底未写操作盘，合理推断为产线操作工按规格调高度、启停电机和风机。装置响应：四缸同步升降；五盘各自旋转；风机连续抽风。

循环：一张接一张过钢。板厚规格切换是分支：停或慢速，升降到位再过钢。交底未写与矫直机联锁。

## 7. 给下游的沉淀

- **发明类型**：结构（实用新型产品）。
- **技术主题（交底）**：一种热处理冷矫直机后的圆盘除尘装置。
- **对象清单（交底用名，不定稿）**：升降框架、圆盘清扫机构、整体式除尘罩、除尘排风系统、冷矫直机出口辊道、液压升降机构、驱动电机、减速器、传动轴、清扫圆盘、耐磨钢丝刷、液压缸、同步控制阀、柔性密封帘、导流板、除尘风机、烟囱、风量调节阀。辊道是安装环境。
- **必要特征候选**（供分流，不是独权条文）：在出口辊道上方；用多组清扫圆盘刮上表面氧化铁皮；圆盘沿板宽布置并前后错位补缝；圆盘由驱动带着转、工作面有刷。升降、整体罩和排风对着交底另外几条痛点，是否进独权由独权构思按「核心区别的完整方案」另判，不在本步定。
- **优选 / 附加特征候选**：五组；前 3 后 2；盘径 300–500 mm；重叠 50–100 mm；液压四缸同步、缸体在基础、活塞杆铰接框架；电机在框架顶；钢丝刷；独立调速；柔性帘及 50–100 mm；导流板；风量阀；风机加烟囱。
- **仍待向发明人确认**：是否只清上表面；密封帘在升降行程里如何保持过钢间隙；有无收尘器；附图标号与正文如何统一；独权是否必须带「五组 / 前 3 后 2 / 液压 / 烟囱」。
- **关键创新点预登记（留给独权构思步骤一正式列表）**：前后排补缝的交叉错位；整体升降适应板厚；整体罩密闭排风；分组独立驱动。
