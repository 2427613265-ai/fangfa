# 理解稿：市政雨污水管道非开挖快速修复加固结构

## 1. 跑通检查

**结论：存疑，核心传力与安装顺序有硬伤级问题。本步停，不进入名词解释。**

按交底，这套东西可以理解成「一块按破损裁切的弧形复合补片 + 内侧几根弧形肋用卡扣拼上 + 边缘胶条和填缝膏 + 两端弹性边卡住管壁」，再从检查井送进去贴到破损处，常温固化。作为**局部贴补防渗**，故事勉强能讲完；作为交底反复强调的**径向抗外压、抗沉降加固**，按现有文字走不通。下面按条摊开，不把发明人没写的关键环节自行补圆。

### 1.1 径向支撑没有支点（硬伤）

- **出处（交底原文）**：衬套为弧形，弧长按破损区域大小裁切；弧形支撑肋贴在衬套内侧，弹性缓冲垫块又贴在肋的内侧；垫块「贴合管道内侧中空区域」，用于缓冲土体沉降、车辆荷载，对破损管道「持续径向支撑加固」。
- **错在哪里**：管内从外到内是「管壁 → 衬套 → 支撑肋 → 垫块 → 管道中空过流区」。土压力和沉降来自管外。要挡住管壁往里塌，支撑必须能把力传到对侧管壁，或者自己围成整环受环压。交底的衬套按破损裁成弧片，肋只排在这块衬套上，垫块对着空腔，空腔里没有对向支座，也没有充气气囊/胀圈一类反力件。
- **会怎样卡住**：破损处继续受外压时，补片连同肋、垫块一起被推进管内，起不到抗外压、抗沉降的作用。技术领域写了「局部塌陷」，这种结构更无法把已塌的管壁顶回去。
- **标记**：传力路径按交底原文；「必须整环或顶到对侧才能抗外压」为合理推断；气囊、胀圈、对侧支撑均为交底未写。

另有一种读法：衬套其实是短管段整周内衬，「点状」只指轴向很短，裁切弧长是为了适配不同 DN 的周长；3–6 组肋卡扣连成整环。这样径向加固才说得通。但交底同时写「按破损区域大小裁切」「点状局部修复、无需整体内衬」，与整周短套矛盾。两种读法不能同时成立，交底未选定。

### 1.2 先锁紧再送入，整环装不进管（硬伤，与 1.1 绑在一起）

- **出处（交底原文）**：施工为「组装径向支撑肋并锁紧固定 → 外侧布胶涂膏 → 井下送入并对位贴合」。卡扣用于「适配不同管径的支撑调节」。
- **错在哪里**：若肋已锁成接近管内径的整环，外径已经顶到工作尺寸，从检查井再推进管内会卡住。行业里通常是送入后再胀开、再锁。交底顺序相反。若只是一块小于管径的弧形补片，则送得进去，但又回到 1.1：锁紧只是把几根肋连在补片上，调不了管径，也胀不紧管壁。
- **会怎样卡住**：整环读法——插不进管；补片读法——插得进但径向加固落空。卡扣「调管径」在两种读法里都没有可执行的中间状态（交底未写可压缩送入、管内再胀开、多档搭接长度等）。
- **标记**：顺序为交底原文；插入与胀紧的矛盾为合理推断；送入后如何胀紧为交底未写。

### 1.3 「一体复合成型」和「常温固化」不是同一件事（硬伤）

- **出处（交底原文）**：衬套三层「一体复合成型」，外侧防渗树脂固化层「直接贴合」破损内壁；施工最后一步「常温固化成型」。
- **错在哪里**：一体复合成型表示下井前衬套已经是成型复合件，树脂层已固化。现场再「常温固化」却没说固的是什么——是填缝膏、额外浸渍树脂，还是未固化的衬套外层？若已固化，和管壁的粘结主要靠填缝膏，衬套本身不再有「固化贴合」；若未固化，又与「一体复合成型」打架。
- **会怎样卡住**：固化对象不明，施工在最后一步接不上；密封和粘管靠什么长期受力也不清。背景批评传统点状修复「仅靠树脂固化层贴合管壁」，本案同样把已成型的树脂层直接贴管壁，区别被说成内侧那组肋，而肋的反力问题见 1.1。
- **标记**：两处表述均为交底原文；固化对象为交底未写。

### 1.4 垫块朝向空腔，缓冲不了土体沉降（硬伤，与 1.1 同源）

- **出处（交底原文）**：垫块在肋内侧，内侧还有防滑纹路；效果写垫块缓冲土体沉降与管道形变。
- **错在哪里**：垫块接触的是过流空腔（或污水），不是土体，也不是对侧管壁。防滑纹路朝管内，对贴管壁没有用。衬套里层已有橡胶柔性贴合缓冲层，夹在衬套和肋之间，那一层才可能缓冲衬套与肋之间的变形；垫块这侧的「缓冲沉降」与力的方向相反。
- **会怎样卡住**：按文字实现不出「缓冲土体沉降」；垫块还会占过流断面，交底未处理阻水、积渣。
- **标记**：位置与效果为交底原文；力流方向为合理推断。

### 1.5 弹性定位条的反力不明（存疑）

- **出处（交底原文）**：弧形定位边在衬套两端，外侧防滑凸起贴管壁，内侧嵌伸缩弹性条，用于限位、防偏移脱空，并自适应管径形变。
- **错在哪里**：弹性条要向外顶定位边贴壁，内侧必须有支点。交底没写它顶在肋上、顶在环向闭合边上，还是仅靠材料自身胀缩。只有两端弹性边、中间是一块未被压紧的弧片时，中部仍会起鼓、脱空——而这正是背景要解决的问题。
- **会怎样卡住**：顶部、侧壁破损时，重力帮不上忙，单靠端部摩擦不一定压住中部。交底未写破损方位，也未写固化前如何保持压紧。
- **标记**：结构为交底原文；反力支点、压紧保持为交底未写。

### 1.6 问题里的「导流」方案里没有（逻辑对不上）

- **出处（交底原文）**：背景第 4 点批评现有技术「无辅助防渗、导流结构」，渗水积在缝里腐蚀修复层。方案有环形胶条和防渗填充膏，没有导流槽、导流管或排水通道。
- **错在哪里**：防渗和导流不是一件事。防渗是堵住；导流是把堵住之前或堵不住的水引走。方案只做了堵。
- **会怎样卡住**：背景列的第四个缺陷没有对应手段。若发明人说的「导流」其实是施工期封堵导流（旁通抽水），交底施工流程也未写停水、封堵、旁通。
- **标记**：问题为交底原文；导流件和施工导流均为交底未写。

### 1.7 管径范围与施工方式对不齐（存疑）

- **出处（交底原文）**：适配 DN300–DN1200；探查用管道机器人；安装写「井下送入」「井下快速装配」；实施例只写 DN600。
- **错在哪里**：DN300 人下不去，必须靠机械送入、对位、压紧；交底未写送入机具，机器人只出现在探查。DN300 与 DN1200 周长差约四倍，仅靠「3–6 组肋 + 按破损裁切」给不出可执行的尺寸链（交底未写肋分规格、卡扣多档搭接量、衬套预弯曲率如何随 DN 改）。
- **会怎样卡住**：小口径装法、大口径装法、曲率匹配都写不全，通用性那条效果落不到结构上。
- **标记**：范围与实施例为交底原文；人不能进 DN300 为合理推断；送入压紧机具为交底未写。

### 1.8 次要瑕疵（不单独构成停步理由）

- 胶条涂膏在地面做好再送入管内，膏料易被蹭掉；交底未写管内再涂或防护。
- 无附图，肋与衬套如何「贴合固定」、卡扣在肋的轴向端还是环向端，只能读字，空间关系容易读岔。
- 「工期缩短 30% 以上」无对比条件，放到效果步再标，不作为跑通硬伤。

### 1.9 按交底走一遍：断在哪

探查破损 → 按尺寸裁衬套 → 拼肋并锁紧 → 外缘上胶涂膏 → 从井送入贴到破损处 → 弹性边限位 → 常温固化。

- 裁片、上胶、送入检查井：文字上能做。
- **断点 A**：锁紧后的结构若接近整环，送不进管；若只是补片，送得进，但贴壁压紧只剩端部摩擦和未标明对象的「固化」。
- **断点 B**：固化对象不明，无法判断何时可以通水。
- **断点 C**：通水后垫块、肋凸在过流区，交底未给出过流与冲刷安排。
- **断点 D**：外压/沉降到来时，没有闭合成环或对侧支点，加固失效。

因此：局部贴补防渗在补齐「压紧方式和固化对象」之后才可能跑通；交底作为卖点的径向加固，按现有结构不成立。

## 2. 名词解释

只求读懂交底用词。不在此定权利要求用名。跑通检查里的矛盾，下面用「本案里打架处」标出，不改结构。

### 非开挖、原位修复

不挖开路面、不把整段管子换成新管，人从检查井下去或把机具送进管内，在原管子内部把破损处补上。交底里的「井下送入」「无需开挖路面」就是这件事。和开挖换管相对。

### 检查井、井下

路面上通向雨污水管的竖井。交底说「井下送入」「井下快速装配」，指从检查井把修复结构送进主管、在管内（或井底）组装对位。DN300 人下不去井后主管，交底却仍写井下装配——见跑通 1.7，此处不补机具。

### DN300–DN1200

DN 是公称直径，单位 mm，市政雨污水常用规格。DN300 约一尺来宽，人钻不进去；DN600 实施例用的规格，勉强可进人作业（仍属有限空间）；DN1200 一人多高。交底用「裁切弧长 + 卡扣拼肋」覆盖这一整段范围，尺寸链未写清。

### 径向、周向、轴向（读本案时的方向）

把管子当成圆筒：

- **轴向**：沿水流、沿管长。
- **周向**：沿管内壁转一圈的方向。
- **径向**：从圆心指向管壁，或反过来从管壁指向圆心。土压把管壁往里压，就是径向向内；要抗外压，就得有径向向外的反力，或整环把力在周向里消化掉。

交底「径向支撑加固」「周向均匀排布」「弧形定位边贴合管道内壁周向」按这套方向读。衬套「外侧」贴管壁、「内侧」朝圆心，全文基本一致。

### 点状修复、整体内衬、点状注浆

| 说法 | 行业里通常指什么 | 本案里指什么 |
| --- | --- | --- |
| 整体内衬 | 很长一段甚至整条管，内壁做一层新衬（CIPP、紫外光固化等） | 交底当反面教材：局部小病害却整段做，浪费 |
| 点状修复 | 只修一小段或一个点，常见是短段**整周**「箍」一圈，也有只贴一块补片的 | 交底强调局部开裂、渗漏、孔洞；衬套又按破损**裁切弧长**，更像补片，不是短段整箍。两种行业含义在交底里没分开 |
| 点状注浆 | 对着渗漏点打树脂/浆，把缝堵住，一般没有内衬骨架 | 交底列为现有非开挖手段之一，本案不用注浆为主 |

**本案里打架处**：效果写「点状局部、无需对管道整体固化内衬」，结构写「弧长按破损裁切」，同时肋又「周向均匀」还要「调不同管径」。读的时候先按「一块弧形补片」理解，整周短套只作为跑通 1.1 的备选读法，不两头靠。

### CIPP 翻转内衬、紫外光固化修复

都是整体（或长段）内衬，不是本案结构。

- **CIPP**：把浸过树脂的软衬管翻进旧管内，贴壁后固化，旧管内壁多出一层新管。翻转是把衬管像袜子一样翻进去。
- **紫外光固化**：衬管就位后用紫外灯烤，树脂固化。和 CIPP 常配套出现。

交底用它们说明：现有非开挖能修，但针对「一个点的破损」成本高、工序重。本案对标的是「局部点修还要带加固」，不是再做一种 CIPP。

### 内衬、衬套、复合加固修复衬套

行业说「内衬」，多指贴在旧管内壁上的那一层新材料。交底主称**复合加固修复衬套**，后文简称复合衬套、复合修复衬套，都是同一件：弧形柔性三层片，外贴破损内壁，内贴支撑肋。

不要理解成管道接口上的橡胶套或钢套管。它是贴在管内壁上的修复层。是整圈还是一块扇形，交底没钉死（见上）。

### 弧形、弧长、环形、周向密封

- **弧形**：顺着圆管内壁弯的那一段曲面，不是平板。
- **弧长**：这段弧有多长。交底说按破损大小裁弧长——按字面是这块补片盖住破损即可，不必绕管一圈。若发明人其实想裁的是「短套的长度」（轴向），交底写的却是弧长，先按字面。
- **环形密封胶条**：胶条绕衬套外轮廓一圈，像创可贴四周的胶。衬套若只是扇形补片，「环形」是补片周边一圈，不是沿管子转一圈的环。交底又写与破损区域「周向密封贴合」，「周向」在管道语境里常被理解成绕管一圈，这里更像「沿破损周边」。先当周边密封读，不升成整管环封。

### 脱空、起鼓、偏移

修复层该贴紧管壁却没贴住：

- **偏移**：补片中心没对上破损点，或安装时滑走。
- **起鼓**：中间鼓包，像贴膜进了气泡。
- **脱空**：和管壁之间有空腔，水会从空腔绕过去。

交底把这三件事主要交给端部弹性定位 + 边缘密封来防。跑通 1.5：只有两端卡住时，中部仍可能起鼓，交底未写安装期如何整面压紧。

### 局部塌陷、开裂、孔洞、接口渗漏、管壁剥落

都是旧管病害，轻重不同：

- 开裂、孔洞、接口渗漏、剥落：壁还在，漏或烂了一块——贴补相对对症。
- **局部塌陷 / 轻微塌陷**：管壁已经被土压瘪了。要先顶回去再加固，或整环把瘪掉的截面撑住。交底把塌陷写进适用范围，结构仍是贴内壁的补片，没有顶管、没有整环胀圆。病害名称保留，不默认本案能复位塌陷。

### 径向支撑、抗外压、抗沉降

- **抗外压**：管外水土往里挤，修复后这个截面还撑得住。
- **抗沉降**：管周土体不均匀往下沉、管子变形时，修复处不跟着再裂。
- 交底的**径向支撑加固组件**：若干弧形肋 + 肋内侧垫块 + 肋与肋之间的卡扣。发明人想用它提供上述抗外压/抗沉降。

**本案里打架处**：垫块朝向管内空腔，肋只附在弧形衬套上，没有对侧支点或闭合成环（跑通 1.1、1.4）。名词上仍按发明人的意图记「这组件被用来做径向加固」；工程上它目前还没有把力传到能抗外压的地方。

### 防渗树脂固化层、一体复合成型、常温固化

- **防渗树脂固化层**：衬套最外层（贴管壁那层），树脂、要防渗。交底写厚度 2–4 mm，并写「直接贴合」破损内壁。
- **一体复合成型**：三层（树脂 + 玻纤 + 橡胶缓冲）出厂或下井前已经合成一块，不是在管内一层层糊。
- **常温固化**：施工流程最后一步，不加热、不照紫外，在环境温度下固化。

**本案里打架处**：已经「一体复合成型」的树脂层，现场再「常温固化」固的是谁，交底没说（跑通 1.3）。相邻概念差在：CIPP/紫外光是**湿衬进管再固化**；本案字面是**成型片进管**，却仍保留一句常温固化。

### 玻璃纤维增强层、柔性贴合缓冲层、弹性缓冲垫块

三层衬套由外到内：树脂 → **玻纤网** → **橡胶柔性层**。玻纤网加抗拉、抗裂；橡胶层对着支撑肋，让肋和衬套贴紧、吃一点变形。

**弹性缓冲垫块**是另一件：硅胶、3–5 mm，装在**肋的内侧**（更靠圆心），还有防滑纹。交底把「缓冲土体沉降」写在垫块上，不在橡胶层上。和橡胶层不要当成同一个零件。垫块朝空腔、缓冲沉降对不上力的方向，见跑通 1.4。

### 弹性贴合定位组件、伸缩弹性条、防滑凸起

衬套两端的限位边：弧形定位边与衬套一体；外侧一排防滑凸起蹭管壁；内侧嵌一条可伸缩的弹性条，交底说用来适应管径变形。作用是安装时卡住、防滑走。弹性条往外顶时，内侧顶在什么上，交底未写（跑通 1.5）。后文也称弹性定位组件、端部弹性定位组件，同一组件。

### 防渗密封组件、防渗填充膏、导流

- **环形密封胶条**：围在衬套外轮廓，压在破损外围还完整的管壁上，第一道挡水。
- **防渗填充膏**：挤进衬套和管壁之间的小缝，堵渗水通道。
- **导流**：背景批评现有技术既无防渗也无导流。防渗是堵住；导流是把水引走（施工期旁通抽水，或修好后把渗水导离修复层）。方案里只有胶条和膏，没有导流槽、导流管、封堵气囊或旁通。后文遇到「导流」只记为背景里的痛点用词，不当成方案里已有的零件。

### 定位锁紧件、弹性卡扣、卡槽

相邻两根弧形肋的端部，一边扣一边槽，拼上即锁。交底兼作「拆装」和「调不同管径」。卡扣在肋的轴向端还是环向端、有没有多档搭接，交底未写，也无图。先当「肋与肋之间的可拆接头」读，不默认它能把直径从 300 连续调到 1200。

### 土体沉降、车辆荷载传导

管埋在土里：土体往下沉、路面上车碾的力经土传到管壁。交底认为旧管因此开裂、剥落、微塌。本案想靠肋和垫块把这些力接下来——传力是否闭环，仍按跑通检查，不在名词上改写成已经能传力。

## 3. 技术问题

方案还没拆。先分清：谁在什么约束下修、交底承认的现有做法、痛点各条后文能不能对上、本发明真正针对的那一句。问题与手段对不上的，记回跑通检查，不在这里圆。

### 场景与约束

作业对象是城市里已经埋了很久的雨水、污水管。管子长期泡在地下水和污水里，外面还受土体沉降、路面车载挤压，内壁会裂、会漏、会烂出孔、接口会渗，严重时管壁剥落甚至轻微塌下去。

要修的时候，地方往往在核心区、主干道、居民区：不能大面积破路面、不能长期断交通、不能又吵又扬尘。交底把修复限定在**非开挖、原位、针对局部病害**，管径口头覆盖 DN300–DN1200，实施例只落到 DN600。施工入口是检查井；小口径人进不去主管，这一条约束交底没有当约束写，但是客观存在（跑通 1.7）。

病害清单里，开裂、孔洞、渗漏、剥落是「壁还在、局部坏了」；局部塌陷是「截面已经被压瘪」。交底把两类写进同一适用范围，后面手段并没有顶管或胀圆，塌陷这一条先当作场景里多写进去的病害，不默认是本案能解的题。

### 现有做法（只据交底）

交底给出两类，没有具体专利号，理解阶段也不另找对比文件。

1. **开挖换管**：挖开路面把坏管换成新的。能彻底换掉，但破路面积大、工期长、断交通、扬尘噪音、造价高，对不上城市核心区快速抢修。
2. **非开挖**，交底点名三种：CIPP 翻转内衬、紫外光固化、点状注浆。前两种是往旧管内做一层新衬，偏整体或长段老化；点状注浆是对着漏点打浆。交底另外还批评「传统点状修复结构仅靠树脂固化层贴管壁」——这是第三种被当作最接近的点修形态：局部贴一层树脂，没有单独的径向骨架。

发明人认为最别扭的，不是「完全不能非开挖」，而是：**局部一个点坏了，整体内衬划不来；现有点修又只是贴一层胶，贴不稳、撑不住。**

### 痛点（交底四条，和对上手段的情况）

| 交底痛点 | 发明人想对上的手段 | 理解阶段的判断 |
| --- | --- | --- |
| 整体内衬对付局部病害，材料浪费、工序重、成本高 | 按破损裁切的点状衬套，不做整段内衬 | 问题成立，和「局部贴补」这条主线对得上 |
| 点修只靠树脂贴壁，无径向加固，抗外压、抗沉降弱，易再裂再漏 | 衬套内侧弧形肋 + 垫块 + 卡扣 | 问题本身成立；手段传力不闭环（跑通 1.1、1.4），**痛点提出了，加固这条还没真正接上** |
| 缺少限位，易偏移、起鼓、脱空；不能适配不同管径、不同弧度 | 两端弹性定位边；衬套裁弧长；肋用卡扣调管径 | 限位、贴稳是真问题。弹性边只管两端，中部压紧未写（跑通 1.5）。卡扣调 DN300–DN1200 的尺寸链未写（跑通 1.2、1.7）。「不同弧度」若指非圆断面，方案只说适配圆管内壁弧度，**非圆适配是交底未写** |
| 无辅助防渗、导流，缝里积水腐蚀修复层 | 周边胶条 + 缝内填充膏 | 防渗（堵住）有对应件。导流（把水引走）方案里没有（跑通 1.6），**第四条痛点只接上了半句** |

另外，开挖换管的破路、断交通、污染，被非开挖这个总前提接住，不是本案结构区别于其他非开挖的那一点。

### 核心问题（一句）

在不能开挖的城市管段上，对雨污水管的**局部**破损、渗漏做原位修复时，整体内衬成本过高，而现有点状修复难以贴稳管壁、也没有可靠的径向加固，修复后容易再漏、再坏。

这一句里，「贴不稳」和「整体内衬划不来」后文至少有对着写的结构；「没有可靠的径向加固」是发明人认定的核心缺口，但按现有交底还撑不起，后续拆方案时继续当**未闭合的问题**，不把「已经能抗沉降」当成理解结论。

目的句里的「快速施工、通用适配」是约束和期望，不单独升成核心技术问题。「导流」「局部塌陷复位」交底写进了背景或适用范围，后文没有对应手段，不挤进核心问题。

不在本步把问题改写成「需要一种带弹性定位、复合衬套、双重密封和径向肋的结构」——那是方案倒装，不是问题。

## 4. 技术方案（功能模块）

发明类型按交底主线：**结构**。下面按块讲清「是什么、干什么、和谁连、关键形状位置」。安装顺序下一步再串。用交底叫法；有歧义并列写出。没有实际图，空间关系以文字为准，图上才可能看清的标「交底未附图」。跑通里的硬伤在相应模块末尾点一下，不补零件。

整机装在市政管道本体的破损内壁上。从管壁往圆心看，一层层是：

**管壁（破损区）→ 边缘胶条和缝里的膏 → 复合衬套（树脂 / 玻纤 / 橡胶）→ 弧形支撑肋 → 弹性缓冲垫块 → 管内过流空腔。**

衬套两端各有一套弹性贴合定位。肋与肋之间用卡扣连接。四块都在，才是交底写的那套修复结构。

### 4.1 复合加固修复衬套

**是什么：** 一块顺着圆管内壁弯曲的柔性复合片。交底也称复合衬套、复合修复衬套。不是接口上的橡胶套，是贴在破损内壁上的修复层。

**干什么：** 盖住局部破损，外侧防渗、耐污水冲刷，中间加筋防衬套自己裂，内侧拿来贴支撑肋。按破损面积裁弧长，用来做点状修复而不是整段内衬。口头还用来适配 DN300–DN1200。

**和谁配合：** 外侧对管壁；外表面边缘包防渗密封组件；内侧贴径向支撑加固组件；两端与弹性贴合定位组件一体连接。

**形状与层次（由外到内，一体复合成型）：**

| 层 | 交底说法 | 材质/形态 | 作用 |
| --- | --- | --- | --- |
| 最外 | 防渗树脂固化层（也称防渗树脂层） | 厚度 2–4 mm | 直接贴破损内壁，防渗、耐腐蚀、抗冲刷 |
| 中间 | 玻璃纤维增强层 | 网状编织 | 提高强度，防止衬套形变开裂 |
| 最内 | 柔性贴合缓冲层 | 橡胶 | 与支撑肋贴紧，缓冲形变 |

弧度要和圆管内壁一致。实施例按破损面积裁弧长，用在 DN600 局部渗漏开裂。

**必要 vs 优选（仅便于看懂，不是权项）：** 弧形柔性片、外贴破损内壁、内贴支撑，是这块的骨架。三层具体材料、2–4 mm、网状编织、可裁切、DN 范围，交底写在「进一步地」里。

**歧义：** 「两端」是管轴向上游/下游两端，还是弧片的两条环向边，文字没钉死；实施例「弧形定位边贴合管道内壁周向」更像轴向两端各一条顺着周向的边。衬套是扇形补片还是短段整周，仍按跑通 1.1 两种读法并列，本步不选边。

### 4.2 弹性贴合定位组件

**是什么：** 衬套两端的限位边。交底也称弹性定位组件、端部弹性定位组件。子件：弧形定位边、伸缩弹性条、防滑凸起。

**干什么：** 修复作业时把衬套卡在对的位置，防滑走、防脱落、防脱空；交底还说弹性条能适应管径变形。

**和谁配合：** 弧形定位边与衬套端部一体连接（实施例为一端成型）。外侧防滑凸起蹭管壁；内侧嵌伸缩弹性条。弹性条往外顶定位边时，内侧顶在肋上还是顶在别的闭合边上，**交底未写**。

**形状位置：** 两组对称在衬套两端。定位边顺着管内壁周向贴。防滑凸起均布在定位边外侧壁。

**必要 vs 优选：** 两端有限位、防偏移，是这块在总装里的角色。拆成定位边 + 弹性条 + 凸起，以及「一体连接 / 一体成型」，是进一步展开。

**未闭合：** 只有两端卡住时，衬套中部仍可能起鼓（跑通 1.5）。顶部、侧壁破损时靠什么保持整面贴紧，交底未写。

### 4.3 防渗密封组件

**是什么：** 衬套外表面边缘的密封。子件：环形密封胶条、防渗填充膏。没有导流槽、导流管或旁通件。

**干什么：** 胶条压在破损外围仍完整的管壁上，形成第一道封闭；膏填进衬套与管壁之间的小缝，堵住渗水通道。交底称为双层密封防渗。

**和谁配合：** 包覆在衬套外轮廓；胶条对着破损区外围管壁；膏在衬套与管内壁缝隙里。和端部定位一起，交底用来防渗漏、脱空、起鼓。

**形状位置：** 「环形」按补片外轮廓绕一圈读，不是沿整管转一圈的环（名词表已说明）。胶条是粘在衬套上随衬套送入，还是到位后再压，文字只写「外轮廓包覆」「压紧贴合」，施工步是送入前布设胶条、涂膏。

**必要 vs 优选：** 边缘要和管壁密封，是这块的角色。拆成胶条 + 膏两道，是进一步展开。

**对不上的问题：** 背景里的「导流」在本模块没有零件（跑通 1.6）。

### 4.4 径向支撑加固组件

**是什么：** 装在衬套内侧的支撑骨架。子件：若干弧形支撑肋、弹性缓冲垫块、定位锁紧件。交底也称内侧支撑组件、径向支撑结构。

**发明人要它干什么：** 从管内把破损处撑住，提高径向抗压、抗沉降；卡扣拼接还用来调不同管内径；垫块缓冲土压和车载。实施例 4 组肋，一般写法 3–6 组，沿衬套周向均匀排，肋的弧度与管内壁一致。

**和谁配合、位置：**

- 肋贴合固定在衬套内侧（对着橡胶缓冲层）。如何固定（粘、扣、预埋）**交底未写、未附图**。
- 垫块固定在肋的内侧（更靠圆心），弧形硅胶，厚 3–5 mm，内侧有防滑纹；实施例写垫块「贴合管道内侧中空区域」。
- 相邻肋的端部：一边卡扣、一边卡槽，可拆卸拼锁。卡扣在肋的轴向端还是环向端，**交底未附图**。

**必要 vs 优选：** 衬套内侧有弧形肋、肋之间可拆连接、肋更内侧有垫块，是交底独权型叙述里就已经点名的三件。3–6 组、硅胶、3–5 mm、防滑纹、弹性卡扣这种具体形式，是进一步地。

**未闭合（不补结构，只标明）：**

- 垫块朝向过流空腔，没有对侧支座，肋只排在这块衬套上，径向抗外压的力传不出去（跑通 1.1、1.4）。
- 先拼锁再送入：整环插不进管，补片则卡扣调不了管径（跑通 1.2）。
- 垫块防滑纹朝管内，对贴管壁无用；「缓冲土体沉降」写在垫块上，不在衬套那层橡胶上，和力的方向相反。

### 4.5 模块之间怎么咬合（静态）

四块不是并联的四套独立装置，而是包在同一处破损上的一层层结构：衬套是载体；定位在衬套两端；密封在衬套外缘；支撑在衬套朝圆心的一侧。胶条和膏解决「缝怎么堵」；定位边解决「安装时别滑走」；肋和垫块被写成「修好后继续撑着」。现场常温固化在交底施工末步出现，固化对象仍不明（跑通 1.3），本步不把「未固化树脂层」或「只固膏」任一解读写进结构。

没有单独的导流模块，也没有顶管、胀圆、气囊、送入机器人（探查机器人除外）——这些都不是交底里的功能块。

## 5. 整体工作流程

按交底把「这个东西怎么干活」走一遍。分两段：下井前怎么做成一块可送入的修复体，到位后它在管内怎么呆着。人的动作交底写得很粗，装置几乎没有主动动作（没有电机、没有充气、没有控制信号），物料主要是衬套、肋、胶条和膏在空间里被搬来搬去。串不起来的地方回到跑通检查，不补步骤。

### 5.1 起始状态

旧雨污水管埋在土里，局部内壁已开裂、渗漏或有孔（交底还写了剥落、轻微塌陷）。路面不挖开。作业入口是检查井。管内是否还在过水、要不要封堵导流，交底未写。

### 5.2 交底施工链

交底原文顺序：

探查破损 → 按尺寸裁衬套 → 组装肋并锁紧 → 外侧布胶条、涂填充膏 → 井下送入并对位贴合 → 弹性定位限位 → 常温固化。

逐步看传递关系：

**① 探查。** 管道机器人进管，找到破损位置和大致尺寸。这一步只有信息：位置、破损范围。机器人此后不再出现，交底没让它负责送入或压紧。

**② 裁衬套。** 人按破损尺寸裁复合衬套弧长。物料是已经一体复合成型的三层片。裁完得到一块弧度按圆管来的柔性片。在地面还是在井底裁，交底未写。实施例针对 DN600 局部渗漏开裂。

**③ 拼肋并锁紧。** 把 3–6 组（实施例 4 组）弧形肋贴到衬套内侧，相邻肋用卡扣卡槽锁上，垫块事先或同时装在肋朝圆心的一侧。完成后：衬套 + 内侧肋骨架成为一块组合体。交底把「调管内径」也写在这一步的锁紧里。

此处断开（跑通 1.2）：若锁成接近管内径的整环，下一步塞不进管；若只是小于管径的补片组合体，能搬动，但锁紧并不产生胀管力，也谈不上调 DN。交底没有「送入后再打开卡扣胀紧」的分支。

**④ 上胶涂膏。** 在衬套外侧边缘布环形密封胶条，并在贴壁那面涂防渗填充膏。膏还是湿的。交底把这一步放在送入之前，组合体外侧带着未干的膏往井下走。

**⑤ 井下送入、对位贴合。** 把整块组合体从检查井送进主管，挪到破损处，外侧对准破损内壁贴上去。谁送、用什么送：DN600 实施例可以理解成工人进管端进去（合理推断，交底只写「井下送入」）；DN300 人进不去，送入机具交底未写（跑通 1.7）。贴合靠什么力：交底没写手按、配重、对侧支撑或气囊。破损在管底时重力帮忙；在管顶或管侧，重力是阻力——交底未分工况。途中膏是否被蹭掉，交底未写。

**⑥ 弹性定位限位。** 衬套两端的弧形定位边靠外侧防滑凸起蹭住管壁，内侧弹性条「适应管径变形」，把组合体卡住，防偏移脱落。这是安装阶段唯一写明的「卡住」动作。弹性条的反力支点仍不明（跑通 1.5）。卡住两端之后，中部是否被肋压实在管壁上，交底没有单独的压紧步骤。

**⑦ 常温固化。** 环境温度下等固化。固的是填充膏、胶条，还是衬套外层树脂，交底未写（跑通 1.3）。固化期间要不要保持压紧、要不要停水、多久可以通水，交底未写。结束后：修复结构留在破损内壁上，交底视为点状修复完成。肋是留下做永久支撑的（「持续径向支撑」），不是取出的施工内模。

无循环。无「失败则重贴」的分支。无不同管径的不同流程，只有同一条链口头覆盖 DN300–DN1200。

### 5.3 修好之后它怎么「干活」（服役）

交底设想的稳态：

- 污水仍从管中心空腔流过。肋和垫块凸在过流区里，交底未写过流断面、阻水、积渣。
- 胶条 + 膏封住衬套周边和缝，不让水从破损缝绕到管外或冲进衬套背后。
- 外侧树脂层挨着污水冲刷和管壁侧的腐蚀介质。
- 管外土压、沉降、车载传来时，发明人指望弧形肋和内侧垫块把破损区撑住，橡胶层和垫块吃一点变形。

此处断开（跑通 1.1、1.4）：外压从管壁外侧来，垫块对着空腔，没有对侧支点或闭合成环，补片会被一起推向管内。服役阶段的「径向加固」按现有结构没有可执行的传力路径。防渗能否长期成立，取决于贴壁压紧在固化时有没有真正压实；交底没有保持压紧的步骤。

塌陷复位、渗水导流、施工期旁通，流程里都没有对应动作。

### 5.4 一句话串起来（含断点）

机器人把破损位置量回来 → 地上（或井里）按尺寸裁出三层衬套 → 内侧拼上肋和垫块并锁死 → 外侧抹上胶条和膏 → 从检查井把这块组合体送进管、贴到破损处 → 两端弹性边蹭住管壁 → 等常温固化，结构留在管内。

能连续做完的是「裁一块带肋的补片、送进去贴上」；断在锁紧与插入的互斥、贴壁压紧力从哪来、固化对象是什么、以及留下的肋如何抗外压。按交底，它干活的方式就是**一块被送入并贴住的点状补片组合体**，不是可胀开的内衬机具，也不是开挖换管。
